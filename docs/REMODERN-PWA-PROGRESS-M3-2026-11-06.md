> 状態：**共通の題字だけの実装（trk305）**。書斎・基地・書体・適用の操作は未実装です。PWA 側の仕様は、Avatar 側と照合して確定します。

## 1. 結論

- **作品の色は、共通の題字（「trk!」）の文字色にだけ当たります**（PR #101、merge `e719dca`）。
- 作品が無いとき・外れたときは、既定の色へ戻ります。画面の色は保存しません。
- 書斎・基地は、まだ作品の見た目が出ません。見本・一覧は Avatar 側のスキンカタログに任せる方針（決定 E3）のままです。
- 見た目を変えるのは、今のところ題字の 2 色だけです。

## 2. 完了した範囲（trk305）

| 項目 | 内容 |
|---|---|
| 当てる先 | 共通の題字（`.brand h1`＝「trk!」）だけ。「!」（span）も同じ作品の色（accent）を当てる |
| 使う色 | 作品の値のうち `colors.text`（文字）と `colors.accent`（「!」）の 2 つだけ。14 鍵のうち、ほかは使わない |
| 当てる条件 | 共通の領域が「独立」（own）で、作品が選ばれていて、その作品が「共通」に対応しているとき |
| 読みやすさ | 題字の背景との対比が **4.5:1** 未満の色は使わない（既定の色のまま）。背景は、題字の上の半透明の層を重ねて求める |
| 形の検査 | 色は `#rrggbb` の形だけ（作品の検査で通ったもの）。CSS の文字列や URL は入らない |
| 戻す | 作品の選択を外す、作品が外れる、保存を消す、のどれでも既定の色へ戻る |
| 保存 | 画面の色は保存しない（保存は設定の作品一覧のまま） |
| 文言 | 設定の作品欄（4 言語）を「共通の題字（trk!）だけに反映されます」に直した |

**確認**
- 自動テスト：`npm run check` は **1841 pass / 0 fail**。新しい検査は `tests/trk305-remodern-paint.test.mjs`（9 件）。
- 実機の代わりの確認（ヘッドレス Chromium）：作品を保存して再読み込みすると、題字の文字色が変わる。「!」は対比が足りないので当たらない。選択を戻すと既定へ戻る。ページのエラーは 0。確認の手順は `tools/smoke/remodern-paint-smoke.mjs` と `tools/smoke/README.md` の 4。

## 3. 依頼者の判断（推測で決めた点）

依頼者から「推測で大丈夫」と受けて、次の 3 点を推測で決めました。違う場合は直します。

1. 最初の適用先は題字だけ（E3 のとおり）。見出しの書体（`heading.font`）は、まだ当てません。
2. 当てる色は文字色と「!」の 2 つだけ。ほかの鍵（背景・枠など）は、題字には使いません。
3. 対比の基準は 4.5:1。足りない色は落とします。

## 4. まだできていないこと

1. **書斎・基地への適用**（作品の色・書体を、それぞれの領域に当てる）。
2. **書体の供給**：見出し用の書体（DotGothic 系など）の読み込みと適用。書体の権利（上流の固定版・OFL 全文・配布物の整合）は、Avatar 側の確認を待ちます。字種の代替も未実装です。
3. **適用前の影響範囲の表示**と、**戻す操作の画面**。戻すときに、利用者が後から変えていれば上書きせず「競合」と扱う仕組みは、道具（`revert`）としてはあるが、画面にはまだ組み込んでいません。
4. **登録簿との照合**（R3 の②③）：Avatar の登録簿（`catalog/re-modern/index.json`）の写しと照らし、合わない作品は「未確認の作品」と表示する。
5. **旧版からの移行・バックアップ・復元**（R-5）。
6. **実機と支援技術の確認**：iPhone（Safari・PWA）、Android（Chrome）、PC。読み上げ、キーボード、200% 拡大、強制色、動きの低減。
7. 学習室の「キー操作のヘルプ」が開く理由（PWA 側の変更とは別と見ていて、未確認）。
