## 3. 決めたこと

| # | 決めたこと | わけ |
|---|---|---|
| U1 | 届いた **3 つの形をそのまま受ける**（目録 JSON・1 枚・パック・生成物の `.js`） | 「JSON に直してから送り直してください」を無くす。先方が回した生成物をそのまま突き合わせられる |
| U2 | `.js` は **`vm` の中で評価してデータとして読む**（`require`・`fetch`・外への通信は渡さない） | 受け取る側の安全（スクリプトを走らせない・外へ取りに行かせない） |
| U3 | 読み口を **1 か所にまとめる**（`tools/lib/skin-catalog.mjs`） | 取り込みと検査の道具で**同じ読み方**にする（食い違いを無くす） |
| U4 | 見分けは**拡張子ではなく中身**。読み損ねたらもう一方でもう一度だけ試す | `.json` という名前の `.js`、`.js` という名前の JSON が来ても読める |
| U5 | 道具は **`import` しても使える**（`validateSkin`・`checkList`・`reasonFromErrors`） | CI や他の道具から呼べる。直接実行したときだけ画面に出す |
| U6 | 道具の版は **v3**・終了コードの意味は変えない（0＝受け取れる／1＝直すところ／2＝読めない） | 先方の「1＝名なし」と違うことは trk269 から周知済み。ここを動かすと混乱する |
| P1 | スキンの値は**触らない**（`--check` で目録どおりを確認するだけ） | 届いた目録は main と同じ。変える理由が無い |
