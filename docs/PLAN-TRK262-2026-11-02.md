### 1.3 画像1について（大事）

- 画像1は、**画面全体に白っぽい膜がかかり、真ん中に ⏪ ⏸ ⏩ の丸いボタン、下に細いバー**という形です。
  trk の 🖥 全画面ビューアは**この膜を出しません**（出すのは上の細いバーと下の説明だけ）。
- 同じ形になるのは、**ブラウザの画中画（PiP）**・**動画サイトのプレイヤー**・**OS のメディアプレーヤー**です。
- このうち **ブラウザの画中画は、ブラウザが持っている窓**なので、**trk の設定では操作パネルを消せません**
  （ページ側から PiP の枠・ホバーの見た目は変えられません）。同じことが ⧉ の別窓（Document PiP）にも言えます。
- したがって本命は **trk の 🖥 全画面ビューア**（と、必要ならメディアプレーヤーの映像枠）です。

### 1.5 自動字幕の材料（調べたこと・2026-11-02）

| 手段 | 事実 |
| --- | --- |
| trk の中で音声認識 | **できない**。Web Speech API は**マイク入力だけ**（`SpeechRecognition.start(track)` は Chrome 139 以降の実験的な追加で、Safari・Firefox・多くのスマホは不可）。しかも認識は**ブラウザの提供元のサーバー**を使うものが多く、「音を端末の外へ出さない」という trk の方針とぶつかる |
| Windows 11 のライブ キャプション | `Windows + Ctrl + L`。**22H2 以降**、**日本語対応**。初回だけ「音声データを端末内で処理することへの同意」と言語パック（約 100MB）のダウンロード。以後はオフラインでも動く。字幕は**画面の下（設定で上）に OS が重ねる**＝trk の中の字幕ではない |
| macOS のライブキャプション | **Apple シリコン**・macOS 14 以降（日本語は Sonoma 以降）。システム設定 → アクセシビリティ → ライブキャプション。初回に言語データのダウンロード。**マイクを使うときは OS のマイク許可**が要る |
| Chrome のライブキャプション | 設定 → ユーザー補助 → ライブキャプション。初回だけ言語パックをダウンロードし、**認識は端末内**。字幕は**ブラウザの窓の下部**に重なる（ページの中ではない） |
| Android | 設定 → ユーザー補助 → ライブキャプション（対応端末） |
| いちばん正確 | **.srt / .vtt を用意して 💬 字幕 に入れる**（オフライン・端末内・遅延調整つき。trk の字幕はこれ） |

## 2. やること（案）

### A. 🖥 全画面ビューアの「バーの出かた」を選ぶ

設定 `videoMaxChrome`（⚙ → 🎨 見た目、の「全画面の拡大・縮小」の隣）：

| 値 | 触れたとき | 触れていないとき |
| --- | --- | --- |
| `full`（**既定**・今までどおり） | 上＋下を出す | 2.6 秒で消える |
| `bottom` | **下のバーだけ**出す | 2.6 秒で消える |
| `always` | 下のバーだけ・**出しっぱなし** | そのまま |
| `none` | **何も出さない** | そのまま（映像だけ） |

- **暗くする処理は入れません**（バーは半透明の帯だけ。映像に膜を張らない）。`none` でもカーソルは 2.6 秒で隠す。
- `none` でも**閉じられる逃げ道**を必ず残します：ESC／ダブルクリック／映像の外（黒いところ）をクリック／
  **画面上端 24px を触ると 3 秒だけバーを出す**／長押し 600ms でもう一度出す。
- 下のバーの中身（新規）：`⏪10s`・`▶/⏸`・`⏩10s`・シーク線・`1:23 / 3:36`・`🔍`・`⛶`・`✕`。
  上バーは `full` のときだけ。

### B. メディアプレーヤーの映像枠（必要なら）

同じ設定を `.mediaStage` にも効かせます（触れると操作列を隠す／常に出す）。既定は今までどおり「常に出す」。
ただし**この画面はもともと暗くならず、バーも常時表示**なので、効き目は「触れたときに隠れる」だけです。

### C. 字幕の置き場所と大きさ

| 設定 | 値 | 既定 |
| --- | --- | --- |
| `mediaSubsPos`（字幕の置き場所） | `bottom` / `middle` / `top` | `bottom`（今までどおり） |
| `mediaSubsSize`（字幕の大きさ） | `small` / `normal` / `large` | `normal`（今までどおり） |

- 効くのは **trk が描く字幕**（メディアプレーヤーの映像枠・🖥 全画面）。**画中画と OS のライブキャプションは効きません**（向こうの設定）。
- 置き場所は `bottom:10%` などの CSS 変数を切り替えるだけ。4 言語。

### D. 自動字幕の案内（文書＋アプリ内）

- 新規 `docs/AUTO-CAPTIONS-TRK262-2026-11-02.md`：仕組み・できない理由・4 つの選択肢（Windows／macOS／Chrome／Android）・
  **権限の許可**の手順・**字幕が出る場所**（OS の重ね表示・ブラウザの下部）・**trk の字幕との違い**（遅延調整は trk の字幕だけ）・
  「いちばん正確なのは .srt/.vtt」。
- アプリ内：💬 字幕 パネルに **`ℹ 自動字幕について`** の折りたたみ（3〜4 行＋詳しくはこの文書）。4 言語。
- 秘密保持：マイクは**取りません**。権限のダイアログも出しません（OS 側の話であることを明記）。
