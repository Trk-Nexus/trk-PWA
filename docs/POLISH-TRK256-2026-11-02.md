## 1. A の束（画面の小粒）

### S2 オフラインでも書類を開ける

`sw.js` の先読みは `index.html` が読み込む CSS・JS・アイコン＋`PRECACHE_EXTRA` だけで、`docs/` は `PRECACHE_SKIP` で外していました。そのため**一度もオンラインで開いていない書類**（クレジット・プライバシー・追加機能の説明）は、オフラインだと fetch が index.html に落ちて「アプリが再表示」されていました。

- `PRECACHE_EXTRA` に `credits.html`・`privacy.html`・`docs/ADDONS.md` の3本を追加（**合計 約36 KB**）
- `docs/` を丸ごと先読みしない方針は維持。例外は `PRECACHE_ALLOW` に**パスを1本ずつ書いたものだけ**（`precacheWanted()` が見ます）
- 増やすときは `PRECACHE_ALLOW` に足す。足し忘れは先読みから漏れるだけで、壊れはしません

### S3 JS が止まっているときの1枚

`<body>` の直後に `<noscript>` を追加（日本語＋英語・インライン CSS・スクリプト無し）。真っ暗な画面の代わりに「JavaScript を有効にしてください」と、開ける書類（README・クレジット）への案内を出します。**読み上げの順序は変わりません**（`display` は既定で `none`、`noscript` の中身は JS 有効時に描画されない）。

### S4 README の起動手順

- `git clone …/trk.git` → **`…/trk-PWA.git`**、`cd trk` → **`cd trk-PWA`**
- 「開発版（このリポジトリ）」と「安定版（`Trk-Nexus/trk`）」の違いを1行ずつ（日英）
- README は **12 KB 上限**（`check-repo`）なので、足した分を同時に削って **12,210 B**

### S5 HANDOFF §1.5 の数字

`1243 pass`（trk246 時点）→ **実際の件数**、cache 名 `trk246` → `trk256`、「`trk-Standalone` はまだ空」→ **組織へ移籍済み／Pages 稼働中／個人リポジトリは空**。設定の行に `swUpdateNotice`・`swUpdateSnooze` を追記。

### S6 「13行」の食い違い

`js/typography.js` のコメントが「上の13行」のままだったので、**`PAIRINGS`（14組）** に。あわせて `sw.js` の `PAIRINGS` を数えて食い違ったら落ちる…ではなく、`check-repo` に **§1.5 の cache 名と `sw.js` の `CACHE` の一致検査**を追加（版を上げて書き忘れる事故の再発防止）。

## 2. B の束（配布物）

### M1 GitHub Actions を commit SHA に固定

`docs/SECURITY-CHECKLIST.md` §C-4 の宿題。タグ（`@v4`）は動くので、上流が乗っ取られると中身が差し替わります。

| 用途 | 固定した SHA | 版 |
| --- | --- | --- |
| `actions/checkout`（check・pages） | `11d5960a326750d5838078e36cf38b85af677262` | v4.4.0 |
| `actions/setup-node` | `49933ea5288caeca8642d1e84afbd3f7d6820020` | v4.4.0 |
| `actions/configure-pages` | `983d7736d9b0ae728b81ab479565c72886d7745b` | v5.0.0 |
| `actions/upload-pages-artifact` | `56afc609e74202658d3ffba0e8f6dda462b719fa` | v3.0.1 |
| `actions/deploy-pages` | `d6db90164ac5ed86f2b6aed7e0febac5b3c0c03e` | v4.0.5 |

- **動きは変わりません**（同じ版の SHA に置き換えただけ）
- `check-repo` に「`uses:` は 40 桁の SHA（＋`# vX.Y.Z` のコメント）」の検査を追加。タグに戻すと落ちます

### M2 mobile-web に開発文書を入れない

`tools/prepare-mobile-web.mjs` が `docs` を**丸ごと**写していたので、HANDOFF・レビュー記録など **70 本・約 2.2 MB** が `cap sync` で端末に入っていました。利用者に要るのは `docs/guide/`（4言語の説明）と `docs/ADDONS.md` だけです。

- `directories` から `docs` を外し、`docsFiles` ＋ `docsDirectories` の一覧で**明示したものだけ**写す
- 実測：`mobile-web/docs` は **2.2 MB → 304 KB**（`mobile-web/` 全体は 30 MB のまま＝減ったのは文書の分）
- **利用者向けの文書を足したら一覧に1行足す**（増やし忘れは `check-repo` が見ます）
