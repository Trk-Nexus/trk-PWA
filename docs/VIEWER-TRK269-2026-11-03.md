## 1. 何が変わったか

### ⌨ ターミナルに、端末の定番が入りました

| 打つ | 何が起きるか |
|---|---|
| `pwd` | いまのスキン・曲・音量を 1 行で返す |
| `ls`（＝`list`・`dir`） | 曲の一覧。`ls 夜` のように言葉を添えると `grep` になる |
| `cd <id>`（＝`skin`） | スキンを移る（唱えたスキンは残る） |
| `cat <番号\|曲名>` | 曲の中身（番号・出どころ・唱え方）。`cat spell <id>` は呪文の本文 |
| `grep <言葉>` | 曲名と出どころの両方から探して番号付きで返す |
| `man`（＝`help`）／`man grep` | 一覧／1 つだけ説明 |
| `history` | 打った呪文（スキンが決めた件数まで） |
| `clear` | 出力を消す（「消しました」だけ残る） |
| `echo <文>` | そのまま返す（呪文の練習用） |
| `bell on`／`bell off` | エラーの音を許す／止める |
| `a \| b` | `;` と同じ「続けて唱える」 |

`play` と同じく、**生のパス（`/` `..` `~` `C:`）は受け付けません**。

### スキンが「操作感」まで決められるようになりました（`cli` の 5 つ）

| 鍵 | 値 | 何が変わるか |
|---|---|---|
| `cursor` | `block`／`underline`／`bar` | カーソルの形（未対応のブラウザーでは無視されます） |
| `opacity` | 0.5〜1 | 端末の地の透け方（**文字は薄くなりません**） |
| `history` | 10〜200 | `↑↓` と `history` の上限 |
| `completion` | `tab`／`off` | `off` なら Tab 補完をしない |
| `bell` | `true` | エラー行が出たときに短い音（**名乗ったときだけ**・設定で止められる） |

何も名乗らなければ、trk268 と同じ見た目・操作です。

### Wizard のスキンが 12 種増えました（スキンは 61 種に）

`wizard-arcane`／`-cli`／`-console`／`-grep`／`-grimoire`／`-history`／`-man`／`-nord`／`-pipe`／`-sudo`／`-terminal`／`-tmux`。

- どれも `cat` に `wizard` を持ち、`cli`（書体・合図・カーソルの色・走査線）も備えています。棚では **🧙 Wizard** の見出しに入ります。
- ⚙ →「⌨ ターミナル」の見た目が `自動` のとき、**これらのスキンがあると端末を開いたときにその色・書体**になります（閉じると元に戻ります）。
- **手で直さないファイル**です（`js/skins-wizard.js`）。目録（Skin 側）から `tools/import-skin-catalog.mjs` で作り直します。

### ⚙ に「エラーの音」が付きました

音は **スキンが `bell: true` と言っていて、このチェックがオンのとき**だけ鳴ります（既定オン）。`bell off` と唱えても切れます。
