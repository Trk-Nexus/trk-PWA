## 2. こちらから 1 つだけ、約束を足しました（trk240）

そちらの CI がこちらの道具を呼ぶということは、**`tools/check-set.mjs` の呼び方と終了コードが「契約」になった**ということです。
ですから、こちらの都合で黙って変えないように、**4 つを固定**して書面にしました（§4-1）。

| # | 固定 | いまの値 |
| --- | --- | --- |
| ① | 呼び方 | `node tools/check-set.mjs <セット> [--hash] [--have=<目録.json>] [--json]` |
| ② | 終了コード | `0`＝入れられる／`1`＝食い違い／`2`＝開けない |
| ③ | `--json` の意味 | 1 行の JSON（`tool`・`version`・`ok`・`problems`・`packs[]`・`missing[]`・`pending`） |
| ④ | `--have` の形 | `{packs:[{id,name,author,version,bytes}]}` か、その配列 |

- **増やす**とき（フラグ・項目）は**先に知らせます**（そちらは無視できるので赤になりません）。
- **減らす・意味を変える**ときは、そちらの CI が赤になるので**必ず先に相談**します。
- 今回足したのは **`--json` だけ**です。人が読む文（既定の出力）は trk239 と同じ形のままにしてあります。`version` は **2**（1＝trk239）。

```sh
$ node tools/check-set.mjs trk-font-set-2026-11-01-r6.stlib --have=catalog/index.json --json
{"tool":"check-set","version":2,...,"pending":{"installed":5,"count":24,"bytes":...,"ids":[...],"skip":5}}
```

**`--json` を使っていただくと、そちらの CI が日本語の文を読まずに済みます**（`pending.count` と `pending.bytes` をそのまま突き合わせられます）。使わなくても今までどおり動きます。
