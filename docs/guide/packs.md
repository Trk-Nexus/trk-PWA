# 📦 パックと公認パック

> 曲パックと ✔ 公認パック。

← [📚 ガイド目次](index.md)　／　[README](../../README.md)

osu! のスキンのように、いろいろなものを1つのファイル（`.stpack`）にまとめて配れます。サーバーはないので、Discordやクラウドストレージなどで共有してください。

- **見た目パック**：スキン・ノーツの色/形/画像・効果音・VRM・モーション・マスコットのセリフ
- **書体パック（trk232）**：`pack.json` の `fonts` に書体（woff2／woff）を同梱できます。使うと本文の書体が同梱の書体になり、外すと元に戻ります
- **ライセンス全文（trk233）**：`fonts[].licenseFile` に `fonts/OFL.txt` などを書くと、パック一覧の「📄 ライセンス全文を読む」で読めます（256KB まで）
- **外すと元に戻ります**：パックが変えたスキン・ノーツ・エフェクトの強さ・SEのオンは、外したときにパックを当てる前の値へ戻ります（`packPrev` として設定に保存されるので、パックを当てたまま再起動しても戻せます）。ただし**パックを使っている間に自分で変えた項目はそのまま**です（自分の変更のほうが新しいので）。**パックを切り替えたとき**も、前のパックを使っている間に自分で変えた項目（スキンなど）はその値が「戻る先」になり、外したあともそのまま残ります（trk132）。
- **曲パック**：音源・譜面・背景画像・BPM・譜面作者の名前・作者のことば（1パック50曲まで）
- 作り方：設定画面の「＋ 今の設定からパックを作る」、選曲画面の「📦 この曲を曲パックにする」
- 入れ方：画面にドロップするだけです。
- `pack.json` の任意の `creditCard` で、作者名・肩書き・権利メモ・利用条件を名刺のように表示できます。`contributors` で最大12人の共同制作者も表示でき、パック内には `CREDITS.md` が自動生成されます。パック一覧から共有用SVG名刺もダウンロードできます。画像を使わないテキスト形式なので、配布先でも扱いやすい設計です。

> ⚠ パックには、**自分に再配布の権利がある素材・曲だけ**を入れてください。
> 中身は ZIP です。形式名 `shadow-taiko-pack` は、以前のパックとの互換のためにそのまま使っています。項目・上限・`pack.json` の例は [docs/pack-format.md](../pack-format.md) にまとめています。
>
> リポジトリの静的な参照・構文検査は `node tools/check-repo.mjs` で実行できます。これは実機ブラウザ確認の代わりにはなりません。

## 📚 倉庫の目録から入れる（trk230）

書体や見た目は大きくなりがちなので、**配る側の倉庫**（[trk-Avatar-Library](https://github.com/TonbokiriRaikiriMuramasa-Taikoubou/trk-Avatar-Library)）に `.stpack` を置き、アプリは**目録を1回読むだけ**で「何が配られているか」を一覧できます。

1. 倉庫から **`catalog/index.json`** を落とす
2. 設定 → 📦 カスタムパック → **📚 目録から入れる** → 「📚 目録（index.json）を選ぶ」
3. 一覧（名前・作者・大きさ・書体数・ライセンス・sha256 の先頭8桁）から、入れたい行の **「この .stpack を選ぶ」**

- **外部へは取りに行きません。** 目録も `.stpack` も、選んだファイルだけを読みます（オフラインのまま使えます）
- 入れる前に **大きさと sha256** を照合し、目録と違えば入れません（`crypto.subtle` が使えない環境だけ「照合せずに入れる」と表示します）
- 目録の形は version 1 です。詳しくは [docs/LIBRARY-TRK230-2026-10-31.md](../LIBRARY-TRK230-2026-10-31.md)

### 📥 まとめて入れる・消す（trk231）

- **📥 まとめて入れる**：目録（`index.json`）と `.stpack` を**一度に選ぶ**か、画面に**まとめてドロップ**すると、名前で突き合わせてまとめて入ります（1件ずつ大きさと sha256 を照合。すでに入っているものは入れ直しません）
- 一覧の行に **未導入／導入済み／使用中** が出ます。導入済みの行は、その場で **「使う」「消す」** ができます（消すときは、使っていれば先に外れます）
- 各行の **🔎 中身** を開くと、ファイル名・大きさ・sha256・書体とライセンスを**入れる前に**確かめられます
### 🔤 書体パック（trk232）

倉庫の「丸ゴのお茶目（書体パック）」のような、**書体を同梱したパック**が、入れて使うと本当に効くようになりました。

- `pack.json` の `fonts` に `family`・`file`・`license`（と任意の `weight`・`style`）を書きます。`file` は **woff2／woff**・1書体 16MB まで・8書体まで。`family` は英数字と空白 `. _ -` の 40 文字まで（倉庫の `verify-pack` と同じ規則なので、倉庫の検査を通ったパックはそのまま通ります）
- 使うと **本文の書体**（`--font`）の先頭に同梱の書体が入ります。**パックのスキンを使っているとき**だけ効き、スキンを持たない書体パックなら、どのスキンにも効きます
- **外す・消すと片付けます**（`document.fonts` から外し、`objectURL` も解放。`--font` も作り直すので、消した書体は残りません）
- 読めなかった書体は数えて「書体を n件 読み込めませんでした。パックの見た目はそのまま使えます。」と出します（外部へは取りに行きません）
- パック一覧に **「書体 n」** と、**同梱の書体・ライセンス**の欄が出ます（書体のライセンス全文はパックの中に残ります）
- **更新あり**：目録の `version` と、入っているパックの `release` が違うと、目録の一覧に「更新あり（1.0.0 → 1.1.0）」と「新しい .stpack を選ぶ」が出ます

### 📄 書体のライセンス全文（trk233）

- `pack.json` の `fonts[].licenseFile`（パック内の `.txt`／`.md`・1ファイル 256KB まで）を入れておくと、**ライセンス全文も保存**され、パック一覧の「🔤 同梱の書体」の中の **「📄 ライセンス全文を読む」** で読めます（押したときだけ読みます）
- 目録の 🔎 中身にも **「ライセンス全文: fonts/OFL.txt」** と出ます
- 全文が入っていない古いパックでは「入れ直すと入ります」と案内します（書体パックを入れ直すと全文も入ります）
- 倉庫には、こちらで作った**書体パック 14 種**を置いています（[docs/FONT-PACKS-TRK233-2026-11-01.md](../FONT-PACKS-TRK233-2026-11-01.md)）

- これから（開発案は [docs/LIBRARY-UX-PLAN-2026-11-01.md](../LIBRARY-UX-PLAN-2026-11-01.md)）：まとめて消す・容量（trk234）／目録とパックを1ファイルにした「セット」（trk235）

## ✔ 公認パック
作曲家さん・譜面作者さんの**本人確認と権利の確認**が済んだ曲パックには **✔公認** が付き、作者さんの「💬 作者のことば」（Xの無料枠と同じ280まで）が表示されます。

- パックのファイル全体の指紋（SHA-256）を、リポジトリの [`verified.json`](../../verified.json) と照らし合わせます。中身が少しでも変わると ✔ は付きません。
- 公認されていない曲パックでも、**譜面作者とBPM**は表示されます。
- 公認の申し込みは X [@ttrk143](https://x.com/ttrk143) の DM か Issues へ。手順と権利のチェックリストは [docs/verified.md](../verified.md) をご覧ください。
