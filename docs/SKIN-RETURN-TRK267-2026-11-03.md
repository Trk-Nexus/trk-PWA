## 3. 受け入れ条件（こちらが「CLI 対応スキン」と認める形）

### A. 見分け方（これが本体・1 語だけ）

- スキン定義の **`cat` に `"wizard"` を 1 語**足す（`cli`／`console` でも通ります・trk268）。
- **id は自由**です（`wizard-cli` を推奨。ただし予約はしていません）。
- 既存カテゴリと**併記してよい**（例：`["dark","wizard"]`）。
- `auto` は `wizard` を含む中で**最初の 1 枚**を選びます。特定の id を既定にしたいときは言ってください（`settings.cliSkin` の既定を変えます）。

### B. 端末が読む色（`ui` の 9 変数＋書体）

| 変数 | 端末のどこに効くか | 必須 |
|---|---|---|
| `--ui-panel` | 端末の地 | ● |
| `--ui-bg` | 入力欄・背景グラデの終点 | ● |
| `--ui-text` | 出力の文字 | ● |
| `--ui-muted` | 下のヒント（キーの案内） | ● |
| `--ui-field` | 出力欄の地 | ● |
| `--ui-border` | 枠・区切り線 | ● |
| `--ui-accent` | プロンプト記号・入力した行 | ● |
| `--ui-accent-ink` | 小さな文字（本体が自動計算。足りなければ `--ui-text` に落ちる） | 任意 |
| `--j-miss`（`game.miss` 由来） | エラーの行 | 任意 |
| `font` | 書体（§4-3 で端末専用の等幅も足せます） | 任意 |

### C. コントラスト（ここだけは満たしてください）

- `--ui-text` と `--ui-muted` が `--ui-panel`／`--ui-field` の上で **4.5:1 以上**
- エラー行の `--j-miss`（= `game.miss`）が `--ui-field` の上で **3:1 以上**
- `--ui-accent-ink` は本体が自動で落とすので、指定しなくて大丈夫です

### D. 目録（`catalog/skins.json`）は「こちらの出力」

> ここが設計書 §2-3 と少し違うところです。先に共有しておきます。

- `catalog/skins.json` は **`tools/export-skin-gallery.mjs` が trk-PWA の `js/data.js`＋`js/characters/miku.js` から作る出力**です（ファイルの `source` にもそう書いてあります）。そちらの手元で足す入力ではありません。
- 流れは「**Skin 側が値を決める → 本体（こちら）が `data.js` に 1 枚入れる → そちらが目録を作り直す**」。
- 目録の作り直しは `node tools/export-skin-gallery.mjs`。`count` が 53→54、`categories` に `wizard: 1` が増えます。`tools/build-catalog.mjs --check` が通れば OK です。

### E. 版（`TRK_PWA_REF`）

- `TRK_PWA_REF` は **`2b3637df1bd52b3b50c36093c442b694c63111a0`**（**40 桁のまま**。短縮しない）。
- `.github/workflows/check.yml` の `env` と `HANDOFF.md` §2.5・§7 を**同じ回**に。
- 上げるのはそちらの判断です。**こちらから push・PR はしません**（前回の r10 のときと同じ扱い）。

## 9. 追記：受け口を先に用意しました（trk268・2026-11-03）

返事を待たずに、**どちらの渡し方でも入る**ようにしておきました。本体の版は **trk268**（`index.html` の `trk-build=trk268`／`sw.js` の `CACHE="trk-v2026.11.03-trk268"` で見分けられます）。

### 9.1 2 つの渡し方

| 渡し方 | 何を送るか | こちらがすること |
|---|---|---|
| ① 値 | JSON 1 枚（`id`・`cat`・`label`・`desc`・`colors`・`font`・`cli`） | `js/data.js` に 1 枚入れて、目録を作り直す |
| ② パック | `.stpack`（`pack.json` の `skin` に同じ値） | 何もしません。**入れた時点で `auto` が拾います** |

### 9.2 名乗り方

`cat` に **`wizard`**（第一候補）／**`cli`**／**`console`** のどれか 1 語。併記できます（例 `["dark","wizard"]`）。
`auto` は「名乗った中で最初の 1 枚 → 無ければ `terminal`」。id は自由です。

### 9.3 端末だけの見た目（任意）

```json
"cli": { "font": "Cascadia Mono, monospace", "prompt": "λ", "caret": "#39ff14", "scan": 0.12 }
```

| 鍵 | 意味 | 通る形 | 既定 |
|---|---|---|---|
| `font` | 書体 | 書体名（120 字まで） | 等幅 |
| `prompt` | 入力の合図 | 1〜4 文字（かっこ・引用符は不可） | `>` |
| `caret` | カーソルの色 | `#rgb`／`#rrggbb`／`currentColor` | 文字色 |
| `scan` | 走査線の濃さ | 0〜0.6（超えると 0.6 に丸め） | 0（なし） |

安全のため、**かっこ・引用符・セミコロン・波かっこ**を含む値は落とします（外部参照を作らせないため）。

### 9.4 送る前に確かめる道具

```bash
node tools/check-cli-skin.mjs wizard-cli.json          # 人が読む
node tools/check-cli-skin.mjs wizard-cli.json --json   # 機械向け（倉庫の CI からもどうぞ）
```

**アプリと同じ `js/data.js`** の計算で見ます：`cat` の名乗り／`colors` の不足／コントラスト（文字 4.5:1・エラー行 3:1）／`cli` の値が通るか。
終了コードは 0＝受け取れる／1＝直すところがある／2＝読めない。**助言の道具**なので、通らなくてもこちらは受け取れます（そのときは理由を添えて返します）。
