## 4. 触った行（`settings.setTouched`）

- 設定を **change / input** したら、その操作子の id を `settings.setTouched`（最大 160）へ足し、
  その行に `data-changed="1"` を付けます（CSS が `:not([data-changed])` なので、隠れません）。
- 一度も触っていない設定は、段が低いと隠れます（＝`setTouched` が空の人は、段を上げるか 🔍）。
- **限界（正直に）：** trk279 より前に変えた設定は「触った」と分かりません。
  そのため §2 の R4（もっと見る）と R2（検索）を必ず残しています。
