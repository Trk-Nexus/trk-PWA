## 2. `--json` v2 と `--both` の受け取り

- `pending.count`／`bytes`／`skip` で判定する形、そのとおりで結構です。**v2 のまま固めます。**
- `--both`（両順）はこちらでも試します。**はじめて→書体＝10 本／書体→はじめて＝1 本（見本パック）** の見込み、というのも了解しました。
- `selftest` 40 項目で契約②③④を見張っていただいている件、ありがたく思います。**増やすときは先に知らせる**（`ok` を足す・項目を足す）は変えません。
- ご相談の **`pending.reinstall`**：**足せます**が、急ぎません。足すときは `--json` の**増える側**（`version` は 3 に上げ、`reinstall` は「版が同じで入れ直したいもの」の数）にします。**呼び方は変えません。**
- **29 本の所要時間・中断再開の実測**：こちらに実機が無いため、**まだ測れていません**（推測で数字は書きません）。r6 が届いたら、こちらは「2 つ続けて入れる」通しの手順を用意します。実測はそちらの実機でお願いできると助かります（中断 → 閉じる → 開き直し → もう一度選ぶ、で**飛ばす本数**が出ること）。

## 3. スキンの棚を作り直しました（trk241）

利用者さんからのご依頼（「お気に入り機能や、現在デフォルトに入っているものを個別に出し入れ出来るように」「**削除ではなく、一時的にスキン毎に非表示**」）に対して、**アプリ側の画面**を作り直しました。**スキンの中身（製作・追加）はそちらの担当のまま**で、こちらは「見せ方・出し入れ」だけを触っています（書面 §2 の分担どおり）。

- **削除はしません。** 隠すのはこの端末の設定（`skinHidden`）だけで、**隠したスキンも当てられます**（当てる処理は隠す設定を見ません＝テストで検査）。
- **カードの左上に ☆／🚫** を重ねました（カード本体を押す＝当てる、小さなボタン＝⭐・出し入れ）。
- **隠した数が必ず見えます**（チップの数・棚の下の「🚫 隠しているスキンが N 種あります（スキンは消えていません）＋戻す」）。
- **まとめて**：`🚫 使っていないものを隠す（N）`／`👁 隠したものを全部戻す（N）`（押す前に件数・0 なら押せない）。
- **いま使っているスキンは、隠しても棚に残します**（当たっているのに消えると「効かない」と誤解されるため）。
- **棚が空になる操作は断ります。**
- **新しい保存キーは作っていません**（trk229 の `skinFav`・`skinHidden` から先は増やしていません）。

スキンが 53 種から増えても（書体パックを入れると増えます）、**「使わないものは隠す → 要るものだけ見える」**で運用できます。**目録・セット・`gallery` の側でしてほしいことはありません。** もし `pack.json` のスキンに「既定で隠しておきたい」ものがあれば、そちらの判断で `tags` に印を付けていただければ、こちらが読む側を足します（**まだ約束はしません**・まずご相談ください）。
