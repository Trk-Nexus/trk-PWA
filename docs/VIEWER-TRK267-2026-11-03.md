## 1. 何が入ったか（1 画面で分かる範囲）

| 入口 | 開き方 |
| --- | --- |
| ⚙ の設定 | 「⌨ ターミナル（trk CLI）」→「⌨ ターミナルを開く」 |
| キーボード | **Ctrl+`**（Mac は **⌘+`**） |
| 閉じる | **Esc**・`quit`／`exit`・右上の ✕ |

選曲画面の上に端末が重なります。開いている間だけスキンを当て（既定は **wizard を含むスキン → 無ければ `terminal`**）、閉じると元のスキンへ戻ります。

### 唱えられる呪文

| コマンド | 例 | すること |
| --- | --- | --- |
| `list` | `list` | 登録ファイルを番号つきで並べる（40 件まで） |
| `play` | `play 2`／`play 夜`／`play next` | その曲を鳴らす（`next`・`prev`・`random`・`fav` も可） |
| `skin` | `skin terminal` | スキンを切り替える（id を省くと今のスキン） |
| `grimoire` | `grimoire`／`grimoire dark` | 魔導書（スキン一覧。`cat` に `wizard` を含むものは ⌨ の印） |
| `volume` | `volume 40` | 音量 0〜100 |
| `seek` | `seek 1:30` | 再生位置（`h:mm:ss` も可） |
| `repeat` | `repeat all` | リピート（`off`／`one`／`all`） |
| `shuffle` | `shuffle on` | シャッフル（`on`／`off`） |
| `spell` | `spell midnight` | 覚えた呪文を唱える（`spell` だけで一覧） |
| `spell add` | `spell add night skin terminal; volume 30` | 呪文を覚える（`settings.cliSpells` に残る） |
| `spell del` | `spell del night` | 忘れる（最初からある 3 本は消せない） |
| `cast` | `cast volume 30; repeat one` | `;` で区切って続けて唱える（入れ子は不可） |
| `help` | `help` | 一覧 |
| `quit`／`exit` | `quit` | 閉じる |

最初から入っている呪文：`shuffle-fav`（お気に入りをシャッフルで 1 曲）・`repeat-all`（全曲リピート）・`midnight`（`terminal` ＋ 音量 30）。

### 設定（⚙ の「⌨ ターミナル」）

| 設定 | 既定 | 意味 |
| --- | --- | --- |
| play の行き先 | **メディアプレイヤー** | `play` で ▶ メディアプレイヤーを開いて鳴らす（端末は閉じる）／もう一つは曲リストの試聴のまま |
| ターミナルの見た目 | **自動** | `auto`＝`cat` に `wizard` を含むスキン → 無ければ `terminal`／`terminal` を必ず当てる／`keep`＝いまのスキンのまま |

保存は `core.settings` の中だけ（`cliPlay`・`cliSkin`・`cliSpells`）。**localStorage のキーは増えていません**。

### 安全のための決め

- `play` は**生のファイルパスを受け付けません**（`/`・`\`・`..`・`~`・`C:` を断り、`list` の番号か曲名だけ）。設計書 §7-3 のトラバーサル対策を「入力にしない」で満たしています。
- 端末は重ね表示の名前 **`cli`** を足したので、開いている間はゲームのキー入力が止まります。**ゲーム中・書斎・メディアプレーヤーを開いている間は開きません**。
- 解禁前のスキン（`locked`）は `skin` で当てられません（理由を 1 行で返します）。
