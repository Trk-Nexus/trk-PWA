## 3. 2 案の見積もり

### 案 A：**全部内蔵**（13 巻 291 種を同梱し、棚で「巻」を選ぶ）

- 生成物：`js/skins-volumes.js`（新規・`tools/import-skin-catalog.mjs` で作る）＋ `js/skins-wizard.js` を 62 種に。
- 増える量：**218 種 × 約 1.45KB ≒ 320KB**（実測：vol-03 の 16 種が 22,786 B、wizard 62 種が 99,428 B）。
  いまの ZIP は 7.6MB なので **+4%**。
- 保存：**新しい保存キー 0**（`core.settings` に `skinShelfVol` を 1 つ足すだけ＝既存の保存に相乗り）。
- オフライン：**確実**（Service Worker の cache に入る）。
- 戻し方：`git checkout <前のREF> -- js/skins-volumes.js index.html` で戻る。
- 心配：棚に 348 枚並ぶ。→ **既定は「定番＋Wizard」だけ出し、巻を選んだときだけその巻を出す**（`content-visibility` で描画も軽くする）。

### 案 B：**巻を選んで取り込む**（アプリ +0KB）

- 画面：⚙ → 🧺 スキン → 📚「巻から取り込む」→ ファイル選択（`vol-01/skins.json` か 1 枚の JSON）→ 中身の一覧 → 選んだ分だけ追加。
- 保存：**IndexedDB を 1 つ**（`trk-skins`・localStorage は 0）。291 種で約 430KB。
- 手間：Drive から ZIP を落として展開し、**巻ごとにファイルを選ぶ**（1 巻 16 枚でも 1 回で済む）。
- 弱み：iOS の「サイトデータを消す」で**消える**／起動時に読むので**最初の一瞬だけ棚に居ない**／
  「どの版を取り込んだか」を自分で覚える必要がある。

### 案 C：**折衷**（Wizard 62 だけ内蔵、229 種は取り込み）

- 端末 ⌨ の体験は**内蔵**（Wizard は「その場で着て試す」もの）。vol.1〜10 は**好み**なので取り込み。
- 増える量：**+41KB**（wizard 38 種）。

| | 案 A 内蔵 | 案 B 取り込み | 案 C 折衷 |
|---|---|---|---|
| アプリの増分 | +約 320KB | 0 | +約 41KB |
| 保存キー | **0** | IndexedDB 1 | 0 |
| 手間（利用者） | **なし** | 巻ごとにファイル選択 | Wizard はなし・他は選択 |
| オフライン | **確実** | IDB 次第 | 確実（Wizard） |
| 20 上限 | 触らない | 別枠が要る | 触らない |
| 実装 | 小（生成＋絞り込み） | 大（画面・保存・削除・重複） | 中 |
| 「選んだものだけ」 | 絞り込みで同じ | 文字どおり | 一部 |

**こちらの推し：案 A。** 目録は 431KB の JSON で、うち 49 種はもう積んでいます。**増分 320KB は ZIP の 4%**。
保存を増やさず、オフラインで確実に着られて、要らなければ「巻を出さない」で隠せます。
案 B は「第 2 版が出たあとで、差分だけ入れたい」ときの道として**将来に残す**のがよいと考えています。

`GoogleChrome/modern-web-guidance-src`（main・1,328 コミット・`features/` `guides/`）を読みました。
**採るのは「今日のブラウザで効いて、効かないブラウザでは黙って素通りする」ものだけ**に絞ります（このアプリは file: でも動く必要があります）。

### 6.1 採る（U4-A の 4 つ）

| G-1 | **`popover`（トップレイヤー・light-dismiss）** | `features/popover.md`・`guides/ui-behaviors/light-dismiss-a-dialog`・`guides/user-experience/content-first-noise-reduction` | 📚「巻から選ぶ」パネル。**モーダルにしない**（読むのを邪魔しない）。`Esc` と外側タップで閉じる |

### 6.2 採らない（理由つき）

| 技 | 出どころ | 採らない理由 |
|---|---|---|
| `document.startViewTransition`（画面の切り替え） | `guides/ui-behaviors/same-document-transitions` | スキンを当てると**画面全体の色が入れ替わる**ので、View Transition の撮影と相性が悪い（撮った絵が古い色のまま残る）。**殻（設定画面）の中でだけ**なら将来入れられる |
| `container-type: scroll-state`（帯を隠す） | `guides/ui-atoms/scrollability-affordance-hints`・`user-experience/content-first-noise-reduction` | まだ新しい。**このアプリは設定画面が主戦場**で、隠す帯が無い |
| `interestfor`（ホバーで予告） | `features/interest-invokers.md` | 触れる端末が主。**ホバー前提の操作は増やさない** |
| `light-dark()`／`color-scheme` の全面採用 | `features/light-dark.md`・`guides/user-experience/preference-aware-ui` | **スキンが色を決める**アプリなので、OS の明暗より**スキンが優先**。`color-scheme` は既に必要な所だけ使っています |
| `customizable-select` | `features/customizable-select.md` | 設定の選択肢は**素の `<select>` のまま**が堅い（キーボードと読み上げが確実） |
