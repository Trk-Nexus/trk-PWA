## 3. 契約の案（そちらの §6）について — **この形で合意できます**

```
settings.typography = { format:"trk-typography", version:1, pairing, preset, base, scale,
                        slots:{ <役>:{family,weight,tracking,leading} } }
```

- こちらの `sanitize()` は**相手の案の項目名をそのまま**通します（`size` のような倍率は、いまは `scale` から決める側にしたので**読んでいません**。入れても捨てずにはおけます）。
- **未知の項目はコピーしない**方針（`sanitizeSkinDef` と同じ）なので、`pack.json` の `skin.typography` を将来読んでも、この版が知らない項目は「消えるだけ」で壊れません。
- **`pack.json` の `skin.typography` は現時点で読んでいません**。「書面で合意してから」という意向どおりです。**読む側の形はこの §3 で確定してよいですか？** 確定なら、こちらの `packRuntime` 側に受け口を置きます。
- Kosugi Maru の **Apache-2.0** の扱い：アプリ側は `licenseFile` を消しません（`tests/trk232` で検査済み）。**表記の追加は不要**です。全文同梱と `NOTICE.md` はそちらの目録側で通っている前提で構いません。
