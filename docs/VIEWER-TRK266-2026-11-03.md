## 2. 作ったもの

### 2.1 F1：理由の行を出すかの判断（純粋な計算）

```js
function pipWhyVisible(st) {
  const v = st || {};
  if (v.ok === true) return false;                 /* 押せるなら出さない */
  if (v.key !== "mediaPipHomeApp") return false;   /* 普通の非対応（Firefox など）は title だけ＝出しっぱなしにしない */
  return v.ready === true;                         /* 読み込む前は「まだ分からない」ので、使えないと書かない */
}
```

- `renderMedia()` は `pipWhyVisible({ ok: pipOk, ready, key: whyKey })` を通し、`pipWhy.hidden = !whyOn;`。
- `aria-describedby` も**行を出しているときだけ**付けます（出していない要素を指さない）。
- ホーム画面アプリの判定は trk265 の `pipStandaloneApp()` ＋ `pipWebkitProbe()` のまま（**要素に聞いた答えを正**にする）。

### 2.2 F2：待ちの間の二度押し

```js
async function togglePip() {
  if (pipBusy) return;          /* 待っている間（最大 2.5 秒）は何もしない */
  ...
  pipBusy = true;
  try { ... } finally { pipBusy = false; syncMediaStage(); renderMedia(); }
}
```

- **閉じる操作は邪魔しません**（`pipBusy` の判定は「開く」側の前だけ。閉じるは `pipIsOn()` を見て先に通る）。
- 実機 1-1 の「**2 回目で出た**」が、この二度押しのせいかどうかも見分けやすくなります。
