# 題字の書体（利用者が導入する書体）— trk315 の実装記録

2026-11-07。Avatar 側の完成資料（`docs/re-modern-research/28`・`30`・`14`・`16`・`22`・`24`・`26`、固定 commit `cb21da9`）を確認して実装した。

## 依頼者の決定（この実装の前提）

| 項目 | 決定 |
| --- | --- |
| 既定の書体 | Galmuri11（一書体で作品名4言語の個々の文字を収録） |
| 候補 | 3つとも設定で切り替え可能（Galmuri11／DotGothic16＋NeoDunggeunmo／Press Start 2P） |
| 配布 | 利用者が導入する形。書体ファイルはリポジトリに入れない。自動取得しない |
| 適用範囲 | 題字（`.brand h1`）と作品名一覧（`#skinGrid .skinCard b`）まで |

## 実装

- `js/title-font.js`（新規）：候補の固定版（SHA-256・bytes）、導入、保存、適用、解除、削除、設定欄の描画。
- `index.html`・`css/style.css`・`js/i18n.js`：設定の書体欄、スコープ限定の1規則、文言（ja・en。zh・ko は en に落ちる）。
- `fonts/licenses/`：OFL 等のライセンス全文4点（固定版から取得し、宣言ハッシュと一致を確認）。書体本体は入れない。
- `tests/trk315-title-font.test.mjs`：13件。

## 守ること（実装の規則）

1. 導入できるのは固定版のハッシュと完全一致したファイルだけ。別版・別ファイルは保存しない。
2. 候補の必要なファイルがすべて揃い、すべて読めたときだけ適用。欠けた・壊れた・保存失敗のときは適用せず、今の題字のまま（部分適用なし）。
3. 適用は `body.trk-title-font-on` と変数 `--trk-title-font` だけ。解除で両方消え、元に戻る。
4. 本文・書斎・基地・ノーツ・既存の書体パック（`--font`）・書体の組み合わせ（trk246）には触らない。
5. 選択と導入ファイルは端末だけに保存（localStorage `trkTitleFont`・IndexedDB `trk-title-font`）。書き出し・バックアップには入らない。

## 未決・限界

- 作品名一覧は `#skinGrid .skinCard b` の名前だけに当てる。作品名の別の場所（詳細画面など）は対象外。
- 書体の字形・読みやすさの人による評価は未了。Galmuri11 の「個々の文字の収録」は cmap の確認であり、文章全体や字形の保証ではない。
- ライセンスの全文は、導入済みでなくても `fonts/licenses/` から読める（オフラインでは読めない場合がある。失敗時はその旨を表示）。
- PWA 側の受け口（作品 pack との連携）は未実装。今回は既存の書体欄とは別の、題字専用の受け口。
- Avatar への返答と、PWA 側の合意の確認は未了。merge は相談の後。
