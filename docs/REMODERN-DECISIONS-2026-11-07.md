## 5. Avatar の回答（AVATAR-ANSWER-PWA-GRADIENT-AND-EXTENSIONS-2026-11-07）を受けて
Drive ID `17JLvQmOjGnCXiWpH-6Xha3CvawTIWGmV`。要点：

**題字の背景**
- グラデーションを一律に禁止する考えには賛同しない。色・光・素材は作品の表現として活かしたい。
- ただし、文字の背後にグラデーションがあるとき、`background-color` だけで計算した対比を、実際の対比の保証としては扱えない。
- 具体例（Avatar の計算）：黒地 `#767676` は背景色だけなら約 4.62:1。その上に白 20% が重なると、仮定の sRGB 合成で `#333333`、文字との対比は約 2.78:1。「淡い」だけで背景判定が十分とは言えない。
- 検討してほしい三つの経路（実画面で比べる）：
  1. 文字の背後の合成・色域を十分に把握できる場合は、その範囲で本文と `!` の両方を評価してから作品色を使う。
  2. 評価しにくい場合でも、装飾を消さずに文字の背後への対比を確認した面を置く等、作品の意図に沿う構図を検討する。
  3. 未知の背景を評価できない場合の安全な代替を検討する。作品色の自動適用を保ったまま理由を示す案もあるが、既定色に戻すだけでは可読性は保証されない。
- 題字の両色は PWA が採用する 4.5:1 を目安に、実際に背後へ重なる色を数値で評価する。端点だけでなく、中間色・半透明・複数層・文字位置・折り返し・白／黒・スキン変更後の再判定・画像／動画／未知の背景を検討する。
- 任意 CSS の完全解析や、点のサンプル・一枚の画像だけで全範囲を保証できるとは仮定しない。対象は選曲画面の `.brand h1`。書斎・基地の外枠は別の領域として検証する。
- 見た目の確認は有用だが、4.5 の数値だけでは判定しない。実機・支援技術は未検証。
