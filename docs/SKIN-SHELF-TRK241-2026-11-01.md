## 1. 依頼（返事10 の ②）

> 「お気に入り機能や、現在デフォルトに入っているものを個別に出し入れ出来るように整える」
> 「スキンの数を作ると、デフォルトで入っている使わないものに煩わしさを与えてしまう体験になる」
> 「**削除ではなく、一時的にスキン毎に非表示を適用出来る形**が良い」

前版（trk229）で **🚫 隠す** と **⭐ お気に入り** は既に入っていました。足りなかったのは **見つけ方と戻し方**です。

| 前版のつらさ | この版でどうしたか |
| --- | --- |
| 隠すには「🧺 整理」を開いて行を探す必要があった（棚のカードからは押せない） | **カードの左上に ☆／🚫 を重ねた**（カード本体を押す＝当てる、小さなボタン＝出し入れ。当てるのと混ざらない） |
| 隠したことに気づけない（🚫 のチップを押さないと見えない） | チップに**数**（`⭐ お気に入り（4）`）／棚の下に **「🚫 隠しているスキンが N 種あります（スキンは消えていません）＋戻す」** |
| 整理の一覧は名前順に全件。スキンが増えると探せない | 整理の一覧にも **さがす・絞り込み（すべて／⭐だけ／🚫だけ／まだ使っていない）・件数** |
| 1 種ずつしか隠せない（29 本の書体が増えたら 1 つずつは現実的でない） | **「🚫 使っていないものを隠す（N）」／「👁 隠したものを全部戻す（N）」**（押す前に件数が見える・0 なら押せない） |
| 隠したスキンを当てていると「効かない」と誤解する | **いま使っているスキンは、隠しても棚に残す**（整理の一覧では `・使用中` の印） |

## 2. 変えないと決めたこと

- **スキンは消さない。** 隠すのは `skinHidden`（この端末の設定）だけで、**当てることはできる**（`applySkin` は `skinHidden` を見ません＝`tests/trk241` で検査）。
- **隠したままでも、いま当たっているスキンは効き続ける**（隠した瞬間に見た目が変わる、という驚きを作らない）。
- **棚が空にならない。** 隠したあとに棚へ残るのが 0 になる操作は断る（`skinCanHide` が `reason:"last"`）。いま使っているスキンを隠すときは、そのスキンが棚に残るので 1 種は必ず見えます。
- **新しい保存キーは作らない。** 使うのは trk229 からの `skinFav`・`skinHidden`・`skinUse`・`skinLast`・`skinShelfOnly`・`skinSort` だけ。整理の**検索語と絞り込みは保存しません**（開くたび「すべて」から）。
- **⭐ は「戻す」の代わりにならない。** ⭐ は棚の上に寄せるだけで、隠したものは隠れたまま（隠すと ⭐ は消える、という紛らわしさを作らない）。

- 「🚫 隠した（9）」を押すと**隠したものだけ**が並び、そこから 👁 で 1 種ずつ戻せます。棚の下の「戻す」は同じ絞り込みへ移動する近道です。
- 「🚫 使っていないものを隠す」は**⭐・いま使っている・もう隠している**を除いた「使ったことのない」ものだけを対象にします（人の判断が入っているものは残す）。

## 4. 中身（`js/core.js`）

| 名前 | 役割 |
| --- | --- |
| `skinShelfEntries(skins, opt)` | 既存。`opt.current` を足した＝**いま使っているスキンは隠しても残す** |
| `skinCanHide(skins, id, hidden, current)` | 純粋。隠してよいか（`{ok, reason}`・`last`／`unknown`） |
| `setSkinHidden(id, on)` | 1 種の出し入れ（保存 → 棚を作り直す） |
| `skinManageRows(skins, opt)` | 純粋。整理の一覧（`filter`＝`all`／`fav`／`hidden`／`unused`＋検索語、名前順） |
| `skinBulkPlan(skins, opt)` | 純粋。まとめて隠す（`mode:"unused"`）／戻す（`mode:"restore"`）の対象。**棚が空にならない範囲**に切る |
| `wireSkinManage()` | 整理の一覧の入力・選択・まとめてボタンの配線（1 回だけ） |
| `buildSkinGrid()` | カードを `.skinCell` で包み、`.skinQuick`（☆／🚫）を重ねる。チップと棚の下に数を出す |
| `buildSkinManage()` | さがす・絞る・件数・まとめての数をそろえて行を作る |

- 通知は `window.Trk.play.showToast`（`js/render.js`）を小さな包み `skinToast` で呼びます（`showToast` は `core.js` の外にあるため）。
- 新しい i18n キーは 4 言語ぶん：`skinOnlyFavN`・`skinOnlyRecentN`・`skinOnlyHiddenN`・`skinHiddenNote`・`skinHiddenRestore`・`skinCantHideLast`・`skinInUseMark`・`skinManageFilterLabel`／`…All`／`…Fav`／`…Hidden`／`…Unused`・`skinManageHideUnused`・`skinManageRestoreAll`・`skinManageCount`・`skinBulkNone`・`skinHiddenDone`・`skinRestoredDone`。
- `sw.js` の cache は **`trk-v2026.11.01-trk241`**（`index.html`・`js/`・`css/` が変わったため）。

## 5. 検査（`tests/trk241-skin-shelf-hide.test.mjs`・28件）

`tests/trk229-skin-shelf-organize.test.mjs` と同じやり方（`extractFn` で `core.js` から純粋関数を抜き、`node:vm` で動かす）。

- **決まり**：隠していないものは隠せる／使用中でも隠せる／最後の 1 種は断る（`reason:"last"`）／もう隠しているものは断らない／知らない id は断る／本物の 53 種でも同じ。
- **棚での扱い**：隠したものは棚から外れる／**使用中は残る**／「🚫 隠した」では隠したものだけ／**隠しても当てる処理は変わらない**（`applySkin` に `skinHidden` が無い）。
- **整理**：名前順／⭐・🚫・まだ使っていない／絞り込みと検索の重ね／知らない絞り込みは「すべて」に倒す／本物のスキンでも数が合う。
- **まとめて**：⭐・使用中・もう隠したものは対象外／棚が空にならない／戻すで全部返る／戻すものが無ければ空／隠して戻すと元どおり。
- **画面と保存**：棚の下の案内／整理の入力と選択肢／カードの ☆・🚫 が当てるのと別のボタン／**新しい保存キーが無い**（整理の検索語・絞り込みは保存しない）／4 言語／案内文が「消えない」と言っている。

## 6. 実機で見ていただきたいこと（未確認）

1. 設定 → 🎨 見た目 → 🖼 スキンの棚。カードの左上の **☆／🚫** が押しやすいか（指で押す大きさか）。
2. 何も隠していない状態と、5 種ほど隠した状態で、**棚の下の案内**が出る／消える。
3. **🚫 隠した（N）** → 👁 で 1 種戻す → 棚の一覧に戻ってくるか。
4. **いま使っているスキン**を 🚫 にしたとき、**そのスキンが棚に残る**ことと、見た目が変わらないこと。
5. 🧺 整理 の **🚫 使っていないものを隠す（N）** → **👁 隠したものを全部戻す（N）** で元どおりになるか。
6. スキンを 1 種だけ残して他を隠そうとしたとき、**断られる**（棚が空にならない）こと。
7. 隠したスキンを、**棚の外（バックアップや `.stpack`）から当てても効く**こと（隠す＝使用禁止ではない）。

## 7. 決めなかったこと（相談したいこと）

- **「隠したものは検索でも出さない」**は入れていません。「🚫 隠した」を見れば探せるため、検索の結果が設定で変わると分かりにくくなると考えました。必要なら入れます。
- **棚の既定を「⭐ と使用中だけ」にする**案は採っていません。何も足していない人が最初に開いたとき、棚がほぼ空になるためです（隠すのは**本人が決めたもの**だけ、という方針）。
- **スキンの「並び順を自分で決める」**（ドラッグ）は入れていません。並べ方は 4 種（おすすめ・名前・よく使う・最近）のままです。
