2026-11-08 ／ 対象：trk321（PR #109 のブランチに追加）。Avatar 38 の A・B・C に対応した範囲と、残りを分けて書きます。

## A. 使用中ではない候補の削除（対応済み）

- 確認文を、いま使っている書体かどうかで分けた。
  - 使用中：「いま使っている書体なので、題字は元の表示に戻ります。」
  - それ以外：「いまの題字は変わりません。」
- 作品の指定の件数は、連携オン・オフ・旧形式を含む「読み取れる候補指定の件数」であり、表示中の件数ではないことを変えていない。指定が残ること、導入し直すまで表示されないことを書く。
- 確認文の組み立ては `removeConfirmText`（試験 E）。

## B. 壊れた保存を 0 件として表示する（対応済み）

- 保存が JSON として読めない・オブジェクトでない・読み取れないときは、件数を `null`（不明）にする。
- 確認文は「保存された作品の指定を読めないため、影響する作品の数は確認できません。保存は消しません。」。0 件とは書かない。
- 読み取り例外（`localStorage` の読み取りが失敗する場合）も同じ扱い（試験 D は不正 JSON で確認。読み取り例外そのものは未注入）。

## C. 削除後の部分失敗（対応済み）

- ファイルの削除は成功したが、選択の解除だけ保存できなかった場合は、`partial` を返す。以前は「保存できませんでした。今の表示は変わりません」と案内していた（実際には表示が外れていた）。
- 新しい案内：「書体のファイルは削除しました。ただし、選択は保存できなかったため残っています。「使わない」を選ぶと、選択を解除できます。」（ja・en）。その後に、読み直した現在の状態の文を続ける。
- ファイルの削除そのものが失敗した場合は、従来どおり `save` と案内し、表示は変えない。

試験：`tests/trk318-title-font-race.test.mjs`（計 21 件）。`npm run check` は 1934/1934 通過（静的検査 0 failure）。
