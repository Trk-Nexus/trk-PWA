## 3. 設計案

### 3.1 領域別の選択（必須）

領域は 3 つ：**共通**・**書斎**・**基地**。各領域は次のどれかの状態を持つ（保存は領域ごとに分ける）。

| 状態 | 意味 |
|---|---|
| `keep` | 現状維持。アップデート前の表示を保つ（共通色を既に継承している箇所はそのまま） |
| `follow` | 共通に連動。共通で選んだ作品に、この領域用の指定があればそれを使い、なければ `keep` と同じ表示 |
| `own` | この領域だけ独立の作品（または既存の表示）を選ぶ。他の領域を変えない |

- 例：「共通A・書斎 keep・基地 B」「共通A・書斎 follow・基地 B」はどちらも表せる。
- 共通の切替は、`own` の独立選択を**上書きしない**。
- 書斎の外枠と本文テーマは別の設定。作品は外枠（枠・余白・見出しなど、可変範囲は下限・上限つき）のみ。本文テーマ・文字サイズ・行間は利用者の設定をそのまま守る。
- 基地は、映像・ジャケット・字幕・再生状態・退出操作を変えない。装飾が映像に重ならないよう、不透明な操作面へ fallback する。

**保存の形（案）**：`trkReModern` のような単一のオブジェクトに `{ common, study, base }` を持ち、各領域は `{ mode: keep|follow|own, work: <作品ID>|null }`。未知の値は `keep` に落とす。具体のキー名は実装前に §4 で確定する。

### 3.2 適用・解除・復元（必須）

- **プレビュー**：一時的な表示のみ。保存しない。
- **適用**：適用前に「何が変わるか」（領域・対象画面・書体・色・影響する利用者設定）を一覧で示す。実行後は取り消せる（直前の状態を一時保存）。
- **解除**：領域ごとに `keep` へ戻す。他の領域・読書・再生・共通ノーツには触れない。
- **元の状態へ戻す**：適用直前のスナップショットを持つ。ただし利用者が後に変えた設定は上書きしない（競合は「変更されています。戻しますか」で確認）。
- 戻す操作は画面外や解除不能なダイアログに閉じ込めない。書斎・基地の閉じる操作は常に見えるようにする。

### 3.3 安全・互換・障害（必須）

- **値の検証**：作品の値は許可リストで検証する（色は許可された型と範囲、書体は許可された名前、装飾は許可された種類）。任意の JS・HTML・CSS・URL の注入はしない。
- **未知・壊れた値**：既存の表示に落とし、利用者の既存データを消さない。`keep` として読み、警告の一文だけ出す。
- **旧版**：旧版が新しい保存を読んだ場合の損失（未知キーの削除）を、テストで確認する。
- **障害時**：素材の欠落・取得失敗・オフライン・保存失敗は既存の表示へ fallback。作品の解除・適用が不可能にならないようにする。

### 3.4 書体（必須・望ましい）

- **既存の仕組みを使う**：書体の組み合わせ（`PAIRINGS`）を作品から参照する。組み合わせの選択は利用者の明示操作とする。
- **見出し用の枠**：`heading` 枠を見出しに限定して使う案は、D2 の決定後に設計する。
- **取り込み**：書体ファイルは、インストール前に書体名・作者・サイズ・ライセンス・取得元を示し、同梱のライセンス全文を後から確認できるようにする。外部 URL からの自動取得はしない。
- **字種**：欠字は字単位で代替する。cmap は描画品質の証明にならないため、実機の表示確認を別に行う。

### 3.5 アクセシビリティ（必須）

- 選択・警告・解除・失敗の案内は、色だけに頼らず文字で示す。
- キーボード・読み上げ・フォーカス復帰・200%・狭い画面・強制色で確認する。
- `prefers-reduced-motion` を尊重する。点滅は使わない。装飾をすべて無効にしても意味と操作が残ること。
