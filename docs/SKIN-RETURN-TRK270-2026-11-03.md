## 4. 検査の道具 `check-cli-skin.mjs` を v2.1 に（誤検知 2 つを直しました）

そちらの目録に当てると **20 種が「色が足りません」** になっていたのは、**こちらの誤検知**でした。すみません。

| 直したこと | 前 | 後 |
|---|---|---|
| 半透明のパネル（`rgba(13,59,13,.97)`） | 「`colors` が足りません：panel」 | 色として受け取る。比は不透明の面（入力欄 → ボタン → 地）で測る |
| `bell: false` | 「cli の値が通りません：bell」 | 「鳴らさない」という正しい書き方として扱う |

いま目録に当てると **12 種 OK／7 種 NG（10 件）**。NG は §3 の「そちらで直せるもの」と同じところです（**目録の生の値**を見ています。本体は取り込み時に寄せます）。

`--catalog` ではなく **目録そのものを引数に渡す**形は前回と同じです：

```
node tools/check-cli-skin.mjs catalog/skins.json          # 目録をまとめて
node tools/check-cli-skin.mjs skin.json --json            # 1 枚を JSON で
```

終了コードは **0＝受け取れる／1＝直すところがある（全部）／2＝読めない**。種類は `--json` の `reason`（`name`／`color`／`contrast`／`cli`）で分かります。
