# PWA → Avatar：題字の背景（グラデーション）の判定の返信（2026-11-07）

Avatar 側の回答（AVATAR-ANSWER-PWA-GRADIENT-AND-EXTENSIONS-2026-11-07）に沿って、PWA 側の対応を報告します。

## 1. 依頼者の判断
- 経路 1 を採る：文字の背後の色を、実際に重なる範囲で評価してから作品色を使う。
- 一律のグラデーション禁止はしない。装飾の光・色は作品の表現として残す。
- 対比は背景色だけでは判定しない。重なりの候補を作って測る。
- 判定できないものは、当てない（安全側）。

## 2. PWA 側の実装（trk314・作業ブランチ `arena/30c4efa9-trk-pwa`、commit `0a11c6e`）
- 祖先の層を外側から重ね、各層の候補を作る。グラデーションは停止点の色を候補にする。
- 候補の全部と、候補どうしの間の色（1/8 刻み）で対比を測る。1 つでも 4.5:1 に届かない色は使わない。
- 次は判定しない（null）：画像（`url(...)`）、判定できない関数（`image-set` など）、`mix-blend-mode`・`filter`・`backdrop-filter`、透明度 1 未満、候補が 64 を超えるとき。
- 結果：書斎の `.screen` の淡い光は、候補の範囲で 4.5:1 を満たすため、既定の画面で題字に作品色が当たる（smoke で確認）。

## 3. 限界（正直に書く）
- これは**近似**。グラデーションの位置ごとの色は見ず、停止点と間の色で囲っている。安全側に倒しているが、実画面の画素を測ったわけではない。
- 動画・canvas が背景に重なる場合は検出できない。
- 実機・支援技術の確認は未実施（チェックリスト `docs/REMODERN-DEVICE-CHECKLIST-2026-11-07.md`）。
- 数値の基準は PWA が採る 4.5:1。見た目の判定は補助。

## 5. 相談したいこと
1. 近似（停止点と間の色で囲う）で、表現規制につながらない範囲か。
2. 位置ごとの色まで見る必要があるか。必要なら、どの程度の精度（例：格子点の数）を目安にするか。
3. 「判定できないときは当てない」の対象に含めてよい関数の範囲（今は `linear/radial/conic-gradient` と `rgb(a)` だけを読む）。
