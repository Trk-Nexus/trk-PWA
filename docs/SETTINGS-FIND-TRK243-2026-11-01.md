## 2. 決めたこと

| # | 決めたこと | 理由 |
| --- | --- | --- |
| 1 | 設定の**いちばん上**に「🔍 設定をさがす」 | 探すための入口は、探す場所の入口に置く |
| 2 | 探す相手は**いま画面に出ている言葉**（`textContent`） | 辞書のキーを別に持たないので、**文言を足しても検索が置いていかれない**。4 言語のどれでも当たる |
| 3 | 空白（**全角も**）で区切った語は**すべて含むもの**（AND） | 「音 音量」で絞れる。1 語だけでも使える |
| 4 | 当たったパネルは**開いて**出す | 閉じたまま「見つかりません」に見えるのを避ける |
| 5 | 当たらないパネルは**その場では隠す**（消さない） | 空にすると**元の開閉**へ戻る。利用者が開いていた形を壊さない |
| 6 | **もともと隠れているものは、検索でも出さない** | 🍎 iPhone のパネル（`.ios-only`）・開発用（`.devOnly`）・条件付き（`#songPackBuilder`）。**見えないものを「見つかりました」と言わない** |
| 7 | **保存は増やさない**（検索語も残さない） | 設定を開くたび、まっさらから。移行の手当て不要 |
| 8 | `✕` と `Esc` で絞るのをやめる | 絞ったことに気づかないまま「設定が消えた」となるのを避ける |

## 5. 検査（`tests/trk243-settings-find.test.mjs`・22件）

- **語の分け方**：空白・全角空白・小文字化／空・`null`・`undefined` は語なし。
- **当たり方**：空なら全員／部分一致（大文字小文字を問わない）／AND／全角空白でも AND。
- **出す・隠す**：検索していないときは `active:false`／当たったものだけ＋件数／**もともと隠れているものは当たっても出さない**／当たらなければ 0 件／語が別々のパネルに分かれたら当たらない／`null` でも落ちない。
- **画面と約束**：検索の入口と `✕`／探す相手は `textContent`（キーから組み立てない）／当たったら開く・当たらなければ `hidden`／空に戻すと元の開閉／**保存キーを作らない**／設定を開くたびまっさら／`Esc`／4 言語／CSS と cache 名。

## 7. 決めなかったこと

- **設定の外（選曲画面など）から設定の項目へ飛ぶ**こと（例：「バックアップ」と検索して開く導線）。今回は設定の中だけです。
