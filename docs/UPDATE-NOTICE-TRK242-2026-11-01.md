## 1. 何が足りていなかったか（事実）

`sw.js` は登録していて、オフライン用にアプリの殻をキャッシュしていました（`js/main.js` 659 行あたり）。
しかし **新しい版が入ったことを画面で知らせる仕組みはありませんでした**（`grep updatefound` が 0 件）。

しかも `sw.js` は install の最後に `skipWaiting()` を呼びます。つまり——

- 新しい版のファイルは**もう端末に届いて、動き出している**
- でも開いている画面は**前の版の JS のまま**
- 利用者は開き直すまで気づけない（次の起動で初めて変わる）

これは「更新したのに反映されない」という、いちばん混乱しやすい形の不具合になります。
（iOS のパネルには「🔄 アプリを更新する」がありましたが、**iOS でしか出ません**＝`js/ios-pwa.js` が `iOS` 以外では早期 return する。）

## 2. 決めたこと

| # | 決めたこと | 理由 |
| --- | --- | --- |
| 1 | 知らせは**画面の下の小さな帯**（窓ではない） | 遊びを止めない。`role="status"`・`aria-live="polite"` で読み上げにも乗る |
| 2 | **初回のインストールでは出さない** | 前の版が無い＝「入れ替わった」ではない。`controller` の有無で判定 |
| 3 | **遊んでいる途中は出さない**。タイトルへ戻ったら出す | 演奏中に帯が出ると視界に入る。`swDeferNotice(phase)`＝`phase !== "title"` |
| 4 | 「いま更新する」＝**開き直すだけ**。「あとで」＝この画面のあいだだけ黙る | 勝手に開き直さない。**新しい保存キーを作らない**（移行の手当て不要） |
| 5 | 確かめるのは**起動時・画面に戻ったとき・30分に1回まで** | 通信を無駄にしない。オフライン優先は変えない（失敗は黙って諦める） |
| 6 | 設定に **「🔄 アプリの更新」**（どの端末でも） | iOS 以外の端末からも、いつでも自分で確かめられる |
| 7 | SW の登録は `js/main.js` から `js/sw-update.js` へ移した | 登録と見張りが同じ場所にないと、見張る相手（`registration`）と離れる |

## 5. 検査（`tests/trk242-update-notice.test.mjs`・22件）

- **出す・出さない**：初回は出さない／待っているときは出す／入れ替わったときも出す／何も無ければ出さない／「あとで」はその画面では出す。
- **後回し**：`title` だけその場で、`playing`・`paused`・空・`result` は後回し。
- **間隔**：29 分では確かめない／30 分で確かめる／見えていないときは確かめない／`CHECK_GAP_MS` は 30 分。
- **結果**：`failed`／`ready`／`latest`。
- **つなぎ方**：登録は `sw-update.js` にあり `main.js` には無い／`index.html` の参照と 7 つの id／帯は `hidden` で `aria-modal` ではない／開き直すのは 1 か所／`updatefound` と `controllerchange` の両方／**保存キーを作らない**／`file:` では登録しない／4 言語／`data-i18n`／cache 名。

## 6. 実機で見ていただきたいこと（未確認）

> **帯だけ先に見たいとき**：`?update=1` を付けて開くと、本物の更新が無くても帯が出ます
> （保存も通信もしない・押しても開き直しません）。`?update=1` は**確認のためだけ**の入口で、
> ふつうの URL では何も起きません。

1. アプリを開いたまま、こちらが新しい版を出す（`sw.js` の cache が変わる）→ **タイトル画面**で帯が出るか。
2. **演奏中**に新しい版が出たとき、帯が出ないこと。演奏が終わってタイトルへ戻ったときに出ること。
3. 「あとで」→ 帯が消えて、その画面では二度と出ないこと。開き直すと（新しい版なので）出ないこと。
4. 「いま更新する」→ 開き直して新しい版になること。**記録・設定が消えていない**こと。
5. 設定 → 「🔄 アプリの更新」→「🔄 新しい版を確かめる」が、**新しい版が無いとき**「いまが最新です。」／**あるとき**「新しい版が届いています。」／**圏外**「確かめられませんでした。」。
6. 初回インストール（はじめて開いた端末）で**帯が出ない**こと。
7. iPhone のホーム画面アプリでも、iOS のパネルの「🔄 アプリを更新する」がこれまでどおり動くこと。

## 7. 決めなかったこと

- **版の番号や更新内容を帯に出す**こと。いまは「新しい版の準備ができました」だけです。`sw.js` の `CACHE` から版を読めますが、読むために `sw.js` をもう一度取りに行くことになるので、今回は入れていません。
- **「あとで」を翌日まで覚える**こと（＝保存キーを増やす）。今回は増やしていません。必要なら相談のうえ `MIGRATIONS.md` に書いてから入れます。
- **自動で開き直す**こと。遊んでいる途中の事故になるので、しません。
