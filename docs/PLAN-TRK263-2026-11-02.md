## 0. 3行まとめ

1. いまは **メディアプレーヤーを閉じると、画中画（PiP）も一緒に閉じます**（`closeMedia()` が `exitPictureInPicture()` を呼ぶ）。
   → 「**閉じても残す**」を設定にして、**既定オン**にします。
2. 残すには**再生を続ける**必要があります（`closeMedia` は設定次第で `video.pause()` するため、そのままだと PiP が止まった絵になります）。
   → 画中画が生きている間は「そのまま流す（keep）」に固定します。
3. 画中画を出している間は、**プレーヤー側の映像枠を隠す**（既定オン）。同じ絵が 2 つ出るのを防ぎます。

## 1. いまの作り（読み取った事実）

| 場所 | いまの動き |
| --- | --- |
| `togglePip()`（`js/media-player-mode.js:962`） | 📌 で `video.requestPictureInPicture()` / `document.exitPictureInPicture()`。失敗すると案内を出す |
| `closeMedia()`（`:1508`） | **必ず** `document.exitPictureInPicture()` を呼び、`pipActive = false`。そのあと `mediaExitPlan()` に従って再生を続ける／止める |
| `mediaExitPlan()`（`:1502`） | 手で閉じたとき（`close:true`・タイトル画面）は `previewEnabled` がオンなら `keep`、オフなら `pause`。ゲーム開始は `pause` |
| 抜けたあと | `previewContinue()`（`js/library.js:4307`）が音量を `musicVolume * 0.8` へ静かに下げる（止めてはいない） |
| 映像枠 | `syncMediaStage()`（`:1379`）が `stageWrap.hidden = !mediaOpen`。開いている間は常に出す（画中画と二重になる） |
| 抜き差し | `enterpictureinpicture` / `leavepictureinpicture` で `pipActive` を追従（`:1609`） |
| ゲーム開始 | `core.on("phase", p => { if (p !== "title" && mediaOpen) closeMedia(false); })`（`:1952`） |

### 1.1 画中画の制約（ブラウザー側）

- **PC の Chrome／Edge／Safari だけ**（Safari は `webkitSetPresentationMode` 系。trk は今のところ Chrome 系の API だけを見ている）。**iPhone／iPad・Android は不可**。
- PiP の窓は**ブラウザーが持つ**ので、位置・大きさ・閉じるボタン・（一部の）操作パネルはページから変えられません。
- 画中画は**その `video` 要素そのもの**を映します。trk は曲の再生に同じ `video` を使うので、
  **別の曲を選ぶと画中画の絵もその曲に変わる**、**ゲームを始めるとゲームの曲が画中画に出る**（だからゲーム開始では閉じる）。

## 2. やること（案）

### A. 📌「画中画を、メディアプレーヤーを閉じても続ける」（`mediaPipKeep`・既定オン）

- `closeMedia()` の「必ず閉じる」を、**設定がオンなら閉じない**に変える。
- 残すときは `mediaExitPlan` の結果を **`keep` に固定**（止めない）。音量も試聴の 0.8 倍へ下げない（プレイヤーの音量のまま）。
- 閉じる場面は**残す**：
  1. **ゲームが始まったとき**（`phase !== title`。ゲームの曲が画中画に出るのを防ぐ）
  2. **画中画の ✕**（ブラウザーの窓を閉じたとき＝`leavepictureinpicture`）
  3. **設定をオフにしたとき**（その場で閉じる）
  4. **タブを離れたとき（`document.hidden`）** は、いまも `video.pause()` するので画中画は止まった絵になる（ブラウザーの仕様）

### B. 📌「画中画を出している間は、プレーヤーの映像を隠す」（`mediaPipHideStage`・既定オン）

- `syncMediaStage()` に「画中画が出ているか」を足し、オンなら **`stageWrap` を隠す**。
- 隠すと「どこへ行った？」となるので、**1 行だけ案内**を出す：
  `📌 画中画で表示中` ＋「ここにも表示」（この場だけ戻す）＋「画中画を終了」。
- 画中画が終わったら（`leavepictureinpicture`）、自動で元の映像枠に戻す。

### C. 設定の置き場所・文言・検査

- ⚙ → 🎬 動画キー の並び（壁紙／🔆／🌊 の隣）に **📌 画中画** のサブパネルを足し、2 つのチェックを置く。
- 4 言語（日本語・英語・中国語・韓国語）。
