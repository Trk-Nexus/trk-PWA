## 2. 鍵盤の広さ

| 設定 | 範囲 | 白鍵 | 幅（等倍） |
| --- | --- | --- | --- |
| `25`（従来） | C3（48）〜C5（72） | 15 本 | 630px |
| `49` | C2（36）〜C6（84） | 29 本 | 1,218px |
| `61` | C2（36）〜C7（96） | 36 本 | 1,512px |
| `88` | A0（21）〜C8（108） | 52 本 | 2,184px |

- 幅の計算は純粋関数 `pianoLayoutFor(白鍵数, 使える幅, 合わせ方)`。**fit** は収まるなら最大 1.28 倍まで広げ、
  はみ出すなら縮める（下限 0.45 倍）。それでも入らないときだけ横スクロール。
  **shrink** は 1 画面（下限 0.28 倍）、**scroll** は等倍のまま。
- CSS の `.instPiano{min-width:630px}` をやめ、`min-width` は JS が決める（縮めるモードでもスクロールバーが出ない）。
- 広さ・合わせ方を変えたときだけ、**C4 が真ん中に来る位置**へ寄せる（毎回の再描画では動かさない）。
- 画面の外の音に割り当てが残っているときは「画面の外の音に {n} 個の割り当てがあります（キーを押すと鳴ります）」と知らせる。

### キー割り当ての移行

いままで：`keyMap` は**長さ 25 の配列**で、添字 = `midi − 48`。広さを変えると意味がずれるため、

```js
keyMap = { "48": "KeyZ", "60": "KeyQ", … }   /* 音番号（MIDI）→ キー */
```

へ移しました。保存されている**旧い配列は読み込み時に自動で読み替える**ので、利用者の割り当ては消えません
（`sanitizeKeyMap()` が配列なら `keyMapFromLegacy()` を通す）。壊れた値（範囲外の音番号・予約キー・重複）は捨てます。

## 3. MIDI キーボード（Web MIDI）

- シンセの鍵盤の上に **「🎹 MIDI 入力」の行**：状態（接続中：デバイス名／未接続／未対応／許可なし）、
  「つなぐ」ボタン、最後に受けたメッセージ（動作確認用のモニター）。
- `navigator.requestMIDIAccess({ sysex:false })` は**ボタンの操作で**呼ぶ（Chrome 124 以降は許可の確認が出る）。
- 受けるもの：**ノートオン/オフ**（ベロシティ 0 のノートオンはオフ扱い）・**CC64 サステイン**・
  **CC120/123 オールノートオフ**・**ピッチベンド**（±2 半音）。
- 抜き差しは `statechange` で拾い直す。**シンセを閉じている間は鳴らさない**（閉じたら鳴っている音・ペダル・ベンドを戻す）。
- すでに許可済みのとき（`navigator.permissions.query({name:"midi"}) === "granted"`）だけ、
  開いたときに黙ってつなぐ（設定 `synthMidiAuto`・初期オン）。許可の確認は勝手に出さない。

### 対応していない端末（重要）

| ブラウザ | Web MIDI |
| --- | --- |
| Chrome / Edge / Opera / Samsung Internet（PC・Android） | 対応 |
| Firefox 108+ | 対応（初回に Site Permission Add-On の許可が要る） |
| **Safari（macOS・iPhone・iPad）** | **非対応**（iOS の Chrome も中身は Safari なので同じ） |

このアプリの主な使い先は iPhone なので、**MIDI はパソコンで使う機能**です。非対応の端末では
「このブラウザは MIDI 入力に対応していません（Chrome／Edge のパソコンで使えます）」と出します。
実物の鍵盤での最終確認は残ります（下の §5）。

## 4. 検査

- 純粋関数は `js/synth-mode.js` の「純粋な計算」の範囲にまとめ、**テストがその範囲だけを切り出して**読みます
  （ブラウザも追加パッケージも要りません）。`tests/trk261-synth.test.mjs` **19 件**。
  - 4 つの範囲と白鍵の本数（15／29／36／52）
  - 3 つの幅の合わせ方（fit／scroll／shrink）の拡大率とスクロールの有無
  - MIDI の読み取り（ノート・ベロシティ 0・CC・ベンド・関係ないメッセージ）
  - キー割り当ての移行と、壊れた値の切り捨て
  - 配線の目印（`requestMIDIAccess`・`onmidimessage`・閉じている間の停止・設定の 4 か所・4 言語）
- 実機が無くても配線を試せるよう、`window.Trk.synth.midiMessage([0x90,60,100])` で
  3 バイトをそのまま流せます（シンセを開いているときだけ鳴る）。
