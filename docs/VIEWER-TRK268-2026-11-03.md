## 1. 何が変わったか（見た目は既定で変わらない）

trk267 の CLI に、**スキン側から見た目を受け取る口**を足しました。スキンが何も名乗らなければ、画面は trk267 と同じです。

| 受け取るもの | 何が変わるか | 既定 |
|---|---|---|
| `cat` に `wizard`／`cli`／`console` | 端末を開いている間、そのスキンが当たる（`auto`） | `terminal` |
| `cli.font` | 端末の書体 | 等幅（OS の等幅） |
| `cli.prompt` | 入力の合図（1〜4 文字） | `>` |
| `cli.caret` | カーソルの色（`#rgb`／`#rrggbb`／`currentColor`） | 文字色 |
| `cli.scan` | 走査線の濃さ（0〜0.6） | 0（なし） |

渡し方は 2 つ（**値**を `js/data.js` に入れる／**`.stpack`** の `skin` に入れる）。どちらも同じ見た目になります。
