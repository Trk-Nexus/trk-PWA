## 3. 作ったもの

### ① 取り込みの道具 `tools/import-skin-catalog.mjs`（新規）

```
node tools/import-skin-catalog.mjs <目録.json> [--cat=wizard] [--cli-only] [--out=js/skins-wizard.js] [--check]
```

- `colors` → `ui`／`game` の割り振りは **`buildCustomSkin` と同じ割合**。目録が持っている `muted`／`field`／`button`／`onAccent`／`border` はそのまま。
- 届かない色（エラー色など）は **`fitInk`** で合格点まで寄せる（`wizard-arcane` の `game.miss` が `#0c8fa1` になったのはこれ）。
- `font` の**二重エスケープを戻す**（`\\+"` → `"`）。記号は `[A-Za-z0-9 _,"'-]` 以外を落とす。
- `cli` は **`sanitizeCliLook` に委譲**（本体と同じ関所を通す）。
- `--cat` でカテゴリ、`--cli-only` で **`cli` を持つものだけ**、`--check` で「いまの生成物が目録どおりか」を見る。
- **id 辞書順**に並べるので、同じ目録なら**同じバイト列**。

### ② 生成物 `js/skins-wizard.js`（12 種）

`wizard-arcane`／`-cli`／`-console`／`-grep`／`-grimoire`／`-history`／`-man`／`-nord`／`-pipe`／`-sudo`／`-terminal`／`-tmux`。
`index.html` で **`js/characters/miku.js` の直後**に読みます（起動時のスキン復元より先に要るため）。`js/core.js` の `SKIN_CATS` に `wizard` を 1 語足しました（棚の見出しは `catWizard`・4 言語）。

### ③ 端末の定番（`js/cli.js`）

| 種類 | 中身 |
|---|---|
| 別名 | `ls`／`dir` → `list`、`cd` → `skin`、`man` → `help`（`man <cmd>` は **1 つだけ**説明） |
| 新規 | `pwd`（スキン・曲・音量を 1 行で）／`cat <番号\|曲名>`・`cat spell <id>`／`grep <言葉>`（曲名と出どころの両方）／`history`／`clear`／`echo`／`bell on\|off` |
| 区切り | `;`・改行に加えて **`\|`** も同じ「続けて唱える」 |
| 戻り値 | `execute` は `{ out, quit, clear }`。`clear` は**先にログを消して**「消しました」だけ残す |

`cat` は `play` と同じ関所（生のパスを断る）。`CLI_HELP` に 9 行、4 言語で 26 本ずつ文言を追加。

### ④ `cli` の 5 つ（`js/data.js` ＋ `css/style.css` ＋ `js/cli.js`）

| 鍵 | 受ける値 | CSS 変数 | 効き方 |
|---|---|---|---|
| `cursor` | `block`／`underline`／`bar` | `--cli-cursor-shape` | `.cliInput` の `caret-shape`（未対応のブラウザーでは無視される） |
| `opacity` | 0.5〜1 | `--cli-opacity` | **地（`::before`）だけ**透ける |
| `history` | 10〜200 | — | `↑↓` と `history` の上限 |
| `completion` | `tab`／`off` | — | `off` なら Tab は何もしない |
| `bell` | `true` のみ | — | エラー行が出たときに短い音（**スキンが名乗り、設定がオンのときだけ**） |

### ⑤ 設定画面（`index.html` ＋ `js/cli.js`）

「エラーの音（ピン）を鳴らす」のチェック 1 つと、**そう決まっていることの説明** 2 行（音は名乗ったスキンだけ／Tab 補完・履歴・カーソルの形・地の透け方はスキンが決める）。

### ⑥ 受け入れの道具 `tools/check-cli-skin.mjs` v2

先方版は**1 枚用**（253 種の目録に当てると全件 NG・「1＝名なし」）。こちらは**目録も受ける**ように広げました。

| 変わったこと | 中身 |
|---|---|
| 判定する対象 | **目録を渡したときは CLI を名乗るスキンだけ**。名乗らないものは `notes` に回す（雑音を消す） |
| 道の文字 | `id`・`cli.font`・`cli.prompt` に `/` `\` `` ` `` `~` `:` `..` `C:` が入っていたら断る |
| 5 つの操作感 | `cursor`／`opacity`／`history`／`completion`／`bell` も見る（値が通らなければ理由を出す） |
| **終了コード** | **1 は「直すところがある」全部**にそろえた（名前なし・色・コントラスト・`cli`）。種類は `--json` の `reason`（`name`／`color`／`contrast`／`cli`）で分かる |
| 色の見方 | 目録が `muted`／`button`／`onAccent` を持っていれば**その色で測る**（本体はそのまま使うため） |
