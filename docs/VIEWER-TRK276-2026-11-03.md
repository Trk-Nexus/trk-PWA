# 実機で見てほしいこと（trk276・4 項目）

`trk-build=trk276`。⚙ → 🎨 → 🖼 **スキンの棚** → **📚 巻から選ぶ** で開きます。
この環境にはブラウザがないため、**K-1〜K-4 は未確認**です。自動テストは「その作りになっているか」までです。

| # | すること | 期待 |
|---|---|---|
| **K-1** | 📚 を開き、`Tab` で一覧へ入って **← → ↑ ↓** | フォーカスの枠が**格子の隣**へ動く（行の端は次の行の先頭）。**棚の見た目は変わらない**（矢印では決まらない）。`Enter`／`Space` で決まり、パネルが閉じて **📚 ボタンにフォーカスが戻る** |
| **K-2** | `⌨ キーで選ぶ` → **縦書き（↓ が次）** | **↓** で次のカード、**列の端では隣の列の先頭**へ。`↑` で前へ。`←`／`→` は同じ行の前後の列。**端で止まる** |
| **K-3** | **使わない** を選んで、一覧で矢印を押す | **何も動かない**（ページのスクロールも起きない）。プレイのキー（例：`remote` プリセットの ←→）とぶつからない |
| **K-4** | 4 つのキーを **`KeyJ`／`KeyK`** などに変える | ボタンが「キーを押す…」になり、押したキーが入る。**同じキーを別の向きに割り当てると入れ替え**。`Esc` は**取り消し**（設定は閉じない）。決めたキーで K-1 と同じように動く |

## ついでに見ていただけると助かること

- **端末の幅を変えて**（390px と 1280px）K-1 を。列数が変わっても「次の行の先頭」の動きが同じか。
- **読み上げ**（TalkBack／VoiceOver）：K-1 で動いたとき、カードの名前が読まれるか。決めたあと「📚 vol.2 宝石・鉱石 を出しています（16 種）」が読まれるか。
