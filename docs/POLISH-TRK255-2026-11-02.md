## 2. 実装の要点（ファイル別）

### `index.html`
- `<meta name="trk-build" content="trk255">` を1行（**値の正は `sw.js` の `CACHE`**。`tests/trk255-polish.test.mjs` が一致を見る）。
- 🔤 の `#typoState`（選んだ組の説明）の**すぐ下**に `#typoUse`（`.hint`・`hidden`）。
- 🔄 `#updatePanel` に `#swUpdateNoticeChk`（optout）と `#swUpdateNoticeHint`、`#swUpdateVersion`（いまの版）。
- 英語で直書きだった `aria-label` **13個**を `data-i18n-aria` に置き換え（`grep 'aria-label="' index.html` = **0**）。

### `js/i18n.js`（4言語・1118 キー）
- 追加：`typoUse`（`{use}`）・`swUpdateNoticeChk`・`swUpdateNoticeHint`・`swUpdateVersion`（`{v}`）・
  `ariaSeek`・`ariaFullscreen`・`ariaMasterRush`（書斎の10個は `js/study-room.js` の自前の辞書へ）。
- 更新：`swUpdateLaterStatus` を「24時間は帯を出さない」文言に。

### `js/core.js`
- `settings.swUpdateNotice`（既定 `true`）と `settings.swUpdateSnooze`（既定 `0`＝眠っていない）を `settings` に追加。
- 工場出荷（`?reset=all`）で `true`／`0` に戻す。
- **localStorage のキーは増やさない**（書き出し・読み込みにもそのまま乗る）。

### `js/sw-update.js`
- `SNOOZE_MS = 24時間`。`swNoticeFor()` に `enabled`／`snoozed` を追加（**オフ・眠りのときは `none`**）。
- 「あとで」は `setSnooze(Date.now() + SNOOZE_MS)`。画面を閉じても24時間は出ません。
- 設定のチェックを配線（`core.settings` 経由・`core.on("settings", …)` で追いつく）。
- 自分で「新しい版を確かめる」を押して新しい版があったときは、眠りと「あとで」を解いて知らせる。
- `#swUpdateVersion` は meta から読み、**言語を変えたら追いつく**（`core.on("language")`）。
- ⚠ **このファイルは保存 API を一切触らない**（`tests/trk242` が `localStorage|sessionStorage|indexedDB` の文字列すら禁じる）。
  コメントにその語を書いたら落ちたので、**言い換え**で書いています。

### `js/ui-prefs.js`
- `syncTypo()` が `#typoUse` を毎回組み立てる（`T.byId(pairing).trkUse`）。**選んでいなければ隠す**。
  選択肢そのもの（`option`）は初回しか作らないので、**説明行は別に持つ**のがポイント。

### `js/settings-find.js`
- `slashAllowed(event)`（純粋関数）：`/` のみ・`ctrl/meta/alt` 付きは無視・`isComposing` は無視・
  `input`／`textarea`／`select`／`contentEditable` の中では何もしない。
- 設定のパネルを開いているあいだだけ `keydown` を見る。**検索語は保存しない**。

### `css/player-bar.css`
- `:root` の `--trk-pb-dens-pad/gap/h`（既定 `1`）と、`body.trk-density-roomy/compact/dense` の上書き。
- `.trk-playerbar` の `min-height`・`gap`・`padding` に `calc(… * var(--trk-pb-dens-*))`。**`font-size` は触らない**。

## 4. 実機で見てほしいこと（この版で増えた分）

1. 🔤 で組を選ぶと、説明の下に「trk! では：〜」が1行出る／「使わない」に戻すと消える。
2. ⚙ → 🔄 アプリの更新に「いまの版：trk255」が出る（言語を変えても追いつく）。**帯には出ていない**。
3. 「あとで」→ 開き直しても帯が出ない（24時間）。⚙ の「🔔 新しい版の知らせを出す」を外すと、そもそも出ない。
4. 密度を「ぎっしり」にすると、**下の再生バーの余白と高さだけ**が詰まる（文字は同じ大きさ）。
5. ⚙ を開いて `/` を押すと「設定をさがす」に入る。入力欄の中では `/` がそのまま打てる／日本語入力の変換中は反応しない。
6. 読み上げ（VoiceOver／TalkBack／NVDA）で、再生位置・全画面・MASTER・書斎の操作名が**選んだ言語**で読まれる。
