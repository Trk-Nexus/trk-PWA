### 1.1 画像 1 について（大事）

画像 1 は、画面全体が白っぽく膜がかかり、真ん中に ⏪ ⏸ ⏩、下に細いバーが出ている形でした。
**これは trk の画面ではありません。** trk の 🖥 全画面ビューアは、これまで**暗くする膜を出していません**（上に半透明の帯が出るだけ）。
同じ見た目になるのは **ブラウザーの画中画（PiP）**・**動画サイトのプレイヤー**・**OS のメディアプレーヤー**です。

- **ブラウザーの画中画と ⧉ の別窓は、ブラウザーが持っている窓**なので、ページ（trk）からは枠もホバーの見た目も変えられません。 → trk の設定では消せません。
- そこで、**trk が持っている 2 つの映像画面**（🖥 全画面ビューアと ▶ メディアプレーヤーの映像枠）に、同じ設定を効かせました。

## 3. 作ったもの

### 3.1 設定（`core.settings`）

| 設定 | 値 | 既定 | 出る場所 |
| --- | --- | --- | --- |
| `videoMaxChrome` | `full`／`bottom`／`always`／`none` | **`full`**（今までどおり） | ⚙ → 🎨 見た目 →「映像の操作パネル」 |
| `mediaSubsPos` | `bottom`／`middle`／`top` | **`bottom`** | ▶ メディアプレーヤー → 💬 字幕 パネル |
| `mediaSubsSize` | `small`／`normal`／`large` | **`normal`** | 同上 |

- 3 つとも `core.settings` の中なので **localStorage のキーは増えていません**。`?reset=all`（工場出荷）でも既定へ戻します。
- 値の寄せ方（知らない値は既定へ）は **`js/viewer-chrome.js`** に集約。

### 3.2 🖥 全画面ビューア（`js/video-max.js`）

| 設定 | 触れたとき | 触れていないとき | 止めているとき |
| --- | --- | --- | --- |
| `full` | 上（曲名）＋下（操作） | 2.6 秒で消える（カーソルも消える） | 上下を出す |
| `bottom` | **下だけ** | 2.6 秒で消える | 下を出す |
| `always` | 下を出しっぱなし | そのまま | 下を出す |
| `none` | **何も出さない** | 何も出さない（カーソルだけ消える） | 下を出す |

- **下のバー**：`⏪10s`／`▶ ⏸`／`⏩10s`／**シーク線**／`1:23 / 3:36`／`🔍 100%`／`⛶`／`✕`。
  操作は **1 か所だけ**（上と下で二重に持ちません）。`full` のときは上に曲名だけが出ます。
- **暗くする膜はありません**。バーは半透明の帯（下向きのグラデーション）だけ。
- **逃げ道**（`none` でも閉じられる・操作できる）：
  1. `ESC`（閉じる）／映像の外（黒いところ）のクリック（閉じる）
  2. **画面の上下 24px** に触れる → **3 秒だけ**下のバーを出す
  3. **一時停止中**（`Space`）は下のバーを出す
- 字幕は、下のバーが出ている間だけ少し上へずらします（重ならないように）。

### 3.3 ▶ メディアプレーヤー（`js/media-player-mode.js`）

- `bottom`／`none` のとき、**動画の再生中だけ**、操作列（再生・曲送り・シーク）を 2.6 秒で隠します。
  **触れる（pointermove／pointerdown／focusin）と戻り、止めれば必ず出ます**。
- `full`／`always` は今までどおり常に表示（この画面はもともと暗くならないため、隠すのは `bottom`／`none` のときだけ）。
- 💬 字幕 パネルに **置き場所／大きさの選択**と **「ℹ 自動字幕について」** を追加。

### 3.4 字幕の置き場所・大きさ

| 置き場所 | CSS |
| --- | --- |
| 下（既定） | `bottom:6%`（全画面）／`bottom:10%`（プレーヤー） |
| 中央 | `top:50%` ＋ `translateY(-50%)` |
| 上 | `top:8%` |

| 大きさ | 倍率 |
| --- | --- |
| 小 | `× 0.8` |
| 中（既定） | `× 1` |
| 大 | `× 1.35` |

- 効くのは **trk が描く字幕**（`.videoMaxSubs`／`.mediaSubs`）だけです。**📌 画中画と OS のライブキャプションは向こうの設定**。

### 3.5 自動字幕の案内

- 新規 [`AUTO-CAPTIONS-TRK262-2026-11-02.md`](AUTO-CAPTIONS-TRK262-2026-11-02.md)：4 つの選択肢（Windows 11／macOS／Chrome／Android）・**権限の許可**・**字幕が出る場所**・trk の字幕（SRT/VTT）との違い・trk が中で作らない理由・SRT の最小例。
- アプリ内：💬 字幕 パネルの `ℹ 自動字幕について`（4 言語）。
- **trk はマイクを取りません**（`getUserMedia` を呼びません）。
