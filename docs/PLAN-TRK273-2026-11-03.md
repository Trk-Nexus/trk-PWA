## 2. M2 の直し方（コード）

### 2.1 前の作り（trk271・trk272）

```js
const sandbox = { console, Math, JSON, Object, Array, String, Number, ... };
vm.createContext(sandbox);
vm.runInContext(text + probe, sandbox);   // ← ここで「実行」していた
```

`node:vm` は**安全のための仕組みではありません**。ホストの `Object` を渡しているので、
`Object.constructor("return process")()` でホストの `process` に届き、`getBuiltinModule("fs")` で書き込みまでできます
（レビューで実演つきの指摘・こちらでも再現を確認）。

### 2.2 いまの作り（trk273）

| 段 | 何をするか |
|---|---|
| 1 | `.js` を**文字列として**読む（`fs.readFileSync` だけ・実行しない） |
| 2 | `= [` の直後の**配列リテラル**を探す（`const SKINS_WIZARD = [ … ]`・`export default [ … ]`・`module.exports = [ … ]`） |
| 3 | 無ければ `S["id"] = { … }` の**オブジェクトの代入**を拾う（このアプリの生成物の形）。鍵を `id` として補う |
| 4 | リテラルを**自前の読み取り**で JSON に直す（鍵の引用符の補い・`'…'` → `"…"`・コメント除去・末尾カンマ除去） |
| 5 | `JSON.parse` する。**式・関数・変数・テンプレート文字列**が出てきたら、その場で断る（理由を返す） |

- 実行しないので、`process` にも `fs` にも届きません。
- 読めない書き方は **「JSON で渡してください」**と返します（黙って空にしない）。
- ESM の `export { X };`・`export default`・`module.exports` は**文字として無視**します（前は評価して拾っていた）。

### 2.3 見張り（テスト）

| テスト | 何を固定するか |
|---|---|
| ペイロードを読ませる | `Object.constructor("return process")()` の `.js` を渡しても**ファイルが増えない**（`fs` に届かない） |
| 4 つの形 | 配列・`S["id"] = {…}`・`export`・`module.exports` を読める |
| 断り方 | テンプレート文字列・関数呼び出し・変数は「読めません」と理由を返す |
| 同じバイト列 | JSON からでも `.js` からでも取り込み結果が同じ |
