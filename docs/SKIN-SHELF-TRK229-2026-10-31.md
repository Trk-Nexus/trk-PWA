## 1. 依頼

> 「今の状態では見た目のスキン数を整理する機能は確か作っていなかった筈なので、なにか良いアイディアを検索して検討してみるのも良いかもしれませんね〜」

trk228 でスキンが **44 → 53 種**になり、棚はカテゴリのチップだけで絞る形でした。
「探す」「並べ替える」「自分用に絞る」が無く、53 枚のカードを目で追うしかない状態でした。

## 2. 調べたこと（他のアプリの整理のしかた）

VRChat のアバター管理アプリ（`k0ta0uchi/VRCAvatarLibrary`、BOOTH の AVATAR LIBRARY Manager など）の説明文を読むと、
**共通して次の6つ**を持っています。

| 機能 | この版での対応 |
| --- | --- |
| 名前・メモ・タグでの部分一致検索 | 🔍 **さがす**（名前・説明・カテゴリ語・id を4言語ぶん） |
| タグ・お気に入りでの絞り込み | チップ（カテゴリ＋⭐／🕒／🚫） |
| 追加日時・最終使用・使用回数での並べ替え | **並べる**：おすすめ順／名前順／よく使う順／最近使った順 |
| 使用回数と最終使用日時の記録 | `skinUse`・`skinLast`（この端末だけ・1000万回で頭打ち） |
| サムネイルの一覧表示 | 既存の棚カード（色の点＋名前＋見本の文字） |
| ライブラリ全体の持ち出し | 既存のバックアップ（`skin` の設定は保存済み）＋ `.stpack` |

**「隠す」も入れました。** VRChat のアバター管理でも「使わないものを一覧から外す」需要があり、
53 種あると「自分の好みでないもの」が毎回目に入るためです（消さずに隠すだけ・ここで戻せる）。

## 4. 決めたこと（理由つき）

| 決め | 理由 |
| --- | --- |
| 検索語は**保存しない**（開き直すと空） | 前回の絞り込みが残ると「スキンが消えた」と誤解されるため。並べ方・絞り込み・⭐・🚫 は保存する |
| 🚫 を付けたスキンは**当てられる**（棚から消えるだけ） | いま使っているスキンを隠したときに、適用できなくなると困るため。`applySkin` は変えていません |
| 使用回数は**当てたときだけ**数える | 起動時の復元（`persist=false`）まで数えると、起動のたびに回数が増えてしまうため |
| 検索は**カテゴリ語**も見る | 「dark」「見やすさ」で探せるほうが、カテゴリ名を思い出せないときに強い |
| 件数は**絞り込んだときだけ**「表示／全体」 | ふだんは「（53）」のまま。数字が2つ出ると、消えたように見えるため |
| 隠す・⭐ は**保存キーを増やすが移行不要** | 新しいキー（`skinFav`／`skinHidden`／`skinUse`／`skinLast`／`skinShelfOnly`／`skinSort`）は、無ければ既定に落ちます。`skinShelfCat` は選択肢が `type` 増えるだけ |

## 5. 実装

| 場所 | 中身 |
| --- | --- |
| `js/core.js` | `cleanSkinIdList`・`cleanSkinMap`（保存値の掃除）／`skinSearchText`・`skinMatchesQuery`（検索）／`skinShelfEntries`（絞り込み＋並べ替えの純粋関数）／`toggleSkinList`・`wireSkinFind`・`buildSkinManage`／`buildSkinGrid` の作り直し／`applySkin` の記録 |
| `index.html` | `#skinSearch`・`#skinSort`・`#skinNoMatch`・`#skinManage`（`#skinManageList`） |
| `css/style.css` | `#skinFind`（2列・760px 以下は1列）・`.skinRow`・`#skinGrid:empty{display:none}` |
| `js/i18n.js` | 20キー × 4 言語 |
| `tests/trk229-skin-shelf-organize.test.mjs` | 18件（検索・絞り込み・並べ替え・掃除・配線） |

`skinShelfEntries(skins, opt)` の戻りは `[[id, skin], …]`。`opt` は
`{ cat, only, query, sort, locale, fav, hidden, use, last }` で、**端末にも DOM にも触りません**（テストから同じ関数を動かせます）。
