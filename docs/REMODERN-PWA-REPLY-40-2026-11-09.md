# PWA返答40：trk323 レビュー（01）と Avatar 40 の確認への対応（trk324）

対象：Avatar 40（`docs/re-modern-research/40-trk323-review-followup.md` 相当、PWA main `95baac2`）と、PWA 宛てレビュー 01（2026-11-09）。この返答は PWA の変更の記録で、公開・正式配布・作品の登録・書体の採用を意味しません。

## 1. 保存のキーを捨てない（Avatar 40 の確認事項）

- **原因**：`snapshotWorks` が、長さ 65 以上・空・`__proto__` の作品キーを読み込み時に捨てていた。別の作品を書き換えると、その項目は保存から消えた。
- **対応**：読んだ値はそのまま持つ。読み出しの見方（`normalizeWorks`）だけが、有効な作品 ID と既知の候補を使う。書き戻すときは、読めない項目も残す。
- 試験：`tests/trk324-title-font-keep.test.mjs` の 1（キーの保持）と 5（`__proto__` で既定の値を汚さない）。

## 2. 既存の項目の未知の値を残す（Avatar 40 の確認事項）

- **原因**：既知の作品の項目を書くとき、項目全体を作り直していたため、その中の未知のフィールド（将来の形式）が消えた。
- **対応**：`mergeEntry` で、既存の項目を写してから `font` と `on` だけを変える（連携のオン・オフ、候補の変更）。
- 試験：2（未知の値 `note` が残る）。旧形式の文字列から書くときは、新しい項目になり `on` は既定のオフ。

## 3. 削除の確認のあとに変わった保存を消さない（Avatar 40 の懸念）

- **対応**：画面に表示したとき（`seenRaw`）の保存と、削除の直前の保存を比べる。違えば削除せず、`changed` を返して「確認の後に保存が変わったため、削除していません。もう一度開いて確認してください」と出す。
- 限界：比べてから消すまでの間に別のタブが書く可能性は、同じスクリプトの中では防げない（非協調タブの保護は、引き続き未解決の設計課題）。
- 試験：4（変わっていたら消さない・同じなら消す）。

## 4. 文言（レビュー 01 §3-1・§3-2・§3-3）

- **§3-1 `tfHowTo`**：4 言語とも「中身が固定版と同じなら、ファイル名が違っても導入できる」に揃えた。実装は中身の大きさと SHA-256 だけを見る。
- **§3-2 invalid の削除**：読めない形式（invalid）の保存を消す確認は、別の文にした（退避を先に勧める。書体ファイル・題字の選択・他の設定は消えない）。読取例外（unreadable）のときは、ボタンが出ても消さない（`removeWorksSettings` は読めないときに何もしない）。
- **§3-3 件数**：読めない項目があれば「ほかに読めない項目が N 件あります。『指定だけを削除』を押すと、これも消えます」と出す。件数は今までどおり有効な候補だけ。
- 試験：6（文言の一致と、invalid の確認文が通常と別であること）。
