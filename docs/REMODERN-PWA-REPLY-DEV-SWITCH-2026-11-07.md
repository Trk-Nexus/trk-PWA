## まだやっていないこと（回答の注意に沿って、明示する）
- 印は**題字の色の切り替えだけ**を示す。書斎・基地の外枠は、判定を用意しただけで色は当てない（全テーマの読みやすさを確かめてから）。
- 印は「切り替えが有効」を示す。実際に色が当たっているかは、題字・書斎の状態の表示で確かめる（各領域の状態表示は今後）。
- 作品ファイルの取り込みや検証は、Avatar 側の `tests/re-modern-work-trk309.test.mjs` の手順で行う。trk310 では、題字の判定（既定は当てない・オンで当てる）と作品の扱いは変えていません。変えたのは保存の戻りと印だけです。**trk310 の版（PR の merge 後の main の commit）で、Avatar 側の確認をもう一度お願いしたい**。
- 実機・支援技術・書体（権利確認待ち）は未了。
