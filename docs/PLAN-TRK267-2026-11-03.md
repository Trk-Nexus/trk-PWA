## 3. こちらの当て込み方（案）

### 3.1 置き場所

| 作るもの | 中身 |
| --- | --- |
| `js/cli.js`（新規） | 端末の重ね表示・入力・履歴・コマンド実行。`window.Trk.cli` に `open`／`close`／`run`（試験用）を出す |
| `js/core.js` | 重ね表示の名前に **`cli`** を 1 つ足す（`Trk.overlay.any()` が真になるので、CLI 中はゲームのキー入力が止まる） |
| `index.html` | `<script src="js/cli.js">` を 1 行（`media-player-mode.js` の後ろ） |
| `css/style.css` | `.cliOverlay`／`.cliDialog`／`.cliLog`／`.cliPrompt`（色は**いまのスキンの CSS 変数**から取る＝スキンを増やさない） |
| `js/i18n.js` ではなく `js/cli.js` 内 | 文言は `Object.assign(TEXT.ja/en/zh/ko, …)`（各機能ファイルと同じ流儀）。コマンド名と引数は英語のまま |

### 3.2 命令の形

`list` が出す**番号**（1 から）か、**曲名の部分一致**だけを受けます。

- `play 3` / `play 夜` … `list` の並び（未実行なら `allSongs()` の並び）から選ぶ
- **生のファイルパスは受け付けません**（設計書 §7-3 のトラバーサル対策を「入力にしない」で満たす）。`..`・`/`・`\` を含む語は「パスは使えません」と返す

### 3.3 保存

`core.settings` の中だけ（`settings.cli`）。**localStorage のキーは増やしません**（trk244・trk246・trk255 と同じ方針）。スキン・音量・再生位置は、いまの保存（`core.saveUserPrefs`／`core.applySkin`）をそのまま通します。

### 3.4 試験の形

`js/cli.js` に `/* ==== 純粋な計算（trk267）` 〜 `ここまで ==== */` の目印を置き、**入力を食わせて文字列が返る**純関数だけを vm で読みます（trk266 と同じ流儀）。

- `parseLine` … `"play 3"` → `{ cmd:"play", args:["3"] }`（空行・未知・大文字・余分な空白）
- `parseClock` … `"1:30"` → 90／`"1:02:03"` → 3723／`"90"` → 90／壊れた値は `null`
- `pickTrack` … 番号・部分一致・見つからない・パスの拒否
- 実行側は `run(line, deps)` に**偽の deps** を渡して、副作用の代わりに記録を見る（DOM 無しで通る）

## 4. 決めてほしいこと（U1〜U4）

| # | 問い | 選択肢 |
| --- | --- | --- |
| U1 | **CLI の入口**をどこに置くか | `settings`＝⚙ に「⌨ ターミナル」を 1 つ／`shortcut`＝Ctrl+`（Mac は ⌘+`）だけ／`both`＝両方／`dock`＝曲リストの 🎥 の隣に常設ボタン |
| U2 | **今回どこまで作るか** | `core`＝`play`・`list`・`skin`・`volume`・`seek`・`grimoire`・`help`・`quit`／`full`＝＋`spell`・`cast`（登録マクロの保存まで）／`design`＝設計だけ・実装は次 |
| U3 | **`play` はどこで鳴らすか** | `media`＝メディアプレイヤーを開いて再生／`preview`＝選曲画面の試聴のまま／`both`＝設定で選べる（既定 `media`） |
| U4 | **CLI を開いている間の見た目** | `keep`＝いまのスキンの色のまま（端末風の枠だけ）／`terminal`＝開いている間だけ `terminal` を当て、閉じたら元のスキンへ／`wizard`＝設計書の `wizard-cli` が来るまで `terminal` で代用し、来たら自動で切り替え |

> **決定（2026-11-03・依頼者）**：**U1 `both`**（⚙ と Ctrl+`）／**U2 `full`**（呪文の登録まで）／**U3 `both`**（設定で選ぶ・既定はメディアプレイヤー）／**U4 は「`terminal` を基本にして、wizard-cli 用のスキン（書体・文字色）をしっかり入れ子で整える」**。
> U4 に合わせて、**`auto`＝`cat` に `wizard` を含むスキン → 無ければ `terminal`** にしました（wizard-cli が届いた時点で、こちらの規則を足さずにそのスキンが着きます）。端末の色・書体は `--ui-*`／`--ui-accent-ink` から取るので、スキン側の `colors`・`font` がそのまま効きます。
> マクロは 3 つ（`shuffle-fav`・`repeat-all`・`midnight`）を最初から入れ、`spell add` で覚えた内容は `settings.cliSpells` に残します（新しい保存キーは増やしません）。
