# 実機・支援技術の確認チェックリスト（trk-re-modern・trk313 時点）

作成日：2026-11-07（Asia/Tokyo）。対象：版 `trk313`、作業ブランチ `arena/351ee373-trk-pwa`。
この環境はヘッドレス Chromium のみで、実機・支援技術（スクリーンリーダー等）では確かめていない。
下の項目は、人の手で確かめてもらうための手順。結果は「○／×／対象外」と気づいた点を書く。

## 0. 準備
- [ ] 本番 URL（`https://trk-nexus.github.io/trk-PWA/`）または PR のプレビューを開く。古い版が出るときは、一度再読込（キャッシュ名は `trk-v2026.11.04-trk313@<スコープ>`）。
- [ ] 確認する機器・ブラウザ・OS を記録する（例：Android Chrome、iPhone Safari、Windows Edge、macOS Safari）。
- [ ] 支援技術を使うなら、名前と版を記録する（例：NVDA、VoiceOver、TalkBack、拡大鏡）。

## 1. 既定の状態（開発用の切り替えはオフ）
- [ ] 設定「🎨 スキン」に、通常の利用者向けの切り替えや案内が**出ていない**こと。
- [ ] 未確認の作品の色が、題字・書斎・基地に**当たっていない**こと。
- [ ] 書体・背景・読書画面など、対象外の見た目が変わっていないこと。

## 2. 開発用の切り替え（オンの間）
- [ ] オンにすると、印「Developer test: unverified work」が表示されること。
- [ ] 印の文字は**色に頼らず**読めること（白黒にしても意味が分かる）。
- [ ] 印のボタンでオフに戻り、印が隠れること。
- [ ] 保存に失敗したとき、「Could not save, so the switch was put back」（日本語では同等の文言）が出て、オフへ戻ること。
- [ ] 支援技術で、印とオン・オフの状態が読み上げられること（ボタンの名前・状態）。
- [ ] 再読込後も、切り替えの状態が保存どおりに戻ること。

## 3. 題字の色（作品から取り込む色）
- [ ] 背景が**単色**のとき、題字に色が当たり、読めること（対比が 4.5:1 程度以上を目安に目で確認）。
- [ ] 背景に**実画像**（url）があるとき、題字に色が当たらないこと（trk313）。
- [ ] 装飾の淡いグラデーション（例：`.screen` の光）のときは、題字が読めること。
- [ ] 白背景・暗背景の両方で、文字が沈まないこと。
- [ ] 拡大（ピンチ・ブラウザの 200%）しても、題字が折り返して崩れないこと。

## 4. 書斎・基地への適用と「戻す」
- [ ] 「適用」の前に、影響範囲（どの画面に当たるか）が表示されること。
- [ ] 「適用」のあと、書斎・基地の外枠が変わること。読書画面の本文は変わらないこと。
- [ ] 「戻す」で、適用前の見た目に完全に戻ること（再読込後も）。
- [ ] 支援技術で、適用・戻すのボタンの名前が分かること。

## 5. 読書テーマ 30 種（書斎）
- [ ] 📚 書斎のテーマの一覧に、30 種すべてが出ること（optgroup の見出しも読めること）。
- [ ] 古書（sepia）など、文字が読みにくいと感じるテーマがないこと（smoke では 4.5:1 以上）。
- [ ] 端末の明るさを下げた状態でも、本文が読めること。

## 6. 支援技術・操作
- [ ] キーボードだけで、設定・書斎・基地の切り替え、適用、戻すまで操作できること（Tab の順・フォーカスの見え方）。
- [ ] フォーカスの枠が、どの背景色でも見えること。
- [ ] スクリーンリーダーで、見出し（h1 の題字）と各ボタンの名前が自然に読まれること。
- [ ] 色覚の違い（赤緑など）を模したフィルターで、状態の違いが分かること。

## 7. 記録と報告
- [ ] 結果を Issue か返信文書に書く（機器・版・日付・○／×・気づいた点）。
- [ ] × の項目は、再現手順（操作の順番と見えた文言）を添える。
- [ ] この文書の確認が終わったら、Avatar への返事に結果を書く（確認していない項目は「未確認」と書く）。

## 注意
- ヘッドレス Chromium の結果は、実機の代わりにならない。
- 動画・canvas が背景に重なる場合は、自動では検出できない。目で確かめる。
- 書体は権利確認待ちのため、この確認の対象外（手順 4 は保留）。
