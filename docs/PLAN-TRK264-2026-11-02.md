# 📌 trk264 の洗い出し（Safari でも画中画を使えるようにする）

> 2026-11-02。trk263（画中画を残す・画中画の間は映像を隠す）のあとに出た
> 「Safari 対応も足しましょう」への整理です。
> ここに書いたものは**決定ではありません**。§3 の U1〜U3 に答えてから、決まった順に実装します。

**前提**：`main` = trk263（PR #58 `5d3431d`）。触るのは `js/media-player-mode.js` の 📌 画中画まわり（trk164 から）と、
設定の文言（`mediaPipHint` など 4 言語）、`docs/`。

---

## 0. 3行まとめ

1. いまの判定は**標準 API だけ**を見ています（`document.pictureInPictureEnabled` と
   `video.requestPictureInPicture`）。Safari は `webkitSetPresentationMode` という**別の API** を持つので、
   trk は「非対応」と表示してしまいます。
2. **両方を見て、使えるほうで入る**ようにします（入る・出る・状態・イベントの4つ）。
3. ただし Safari の**ホーム画面アプリ（iPhone／iPad）では、標準 API があっても入らない**という
   ブラウザー側の不具合があります（WebKit bug 303885）。そこは「押せない理由」を言葉にします。

## 1. いまの作り（読み取った事実）

| 場所 | いまの動き |
| --- | --- |
| `pipSupported()`（`js/media-player-mode.js:981`） | `document.pictureInPictureEnabled` **かつ** `video.requestPictureInPicture` があるか。無ければ 📌 を無効にし、`mediaPipUnsupported` を title に出す |
| `togglePip()`（`:1017`） | 標準 API で入る／`document.exitPictureInPicture()` で出る。失敗すると `mediaPipUnsupported` のトースト |
| `exitPip()`（`:1012`） | `document.exitPictureInPicture()` を呼んで後始末（trk263 で追加） |
| `pipIsOn()`（`:1008`） | `pipActive` **または** `document.pictureInPictureElement` |
| イベント（`:1697`） | `enterpictureinpicture` / `leavepictureinpicture` の2つだけ |
| `closeMedia()` の `keepPip`（trk263） | 「小窓が出ているか」を `pipIsOn()` で見ている → **Safari では常に false になる**（小窓が残らない） |

### 1.1 ブラウザーごとの事実（2026-11-02 時点で確認）

| ブラウザー | 標準 `video.requestPictureInPicture()` | `video.webkitSetPresentationMode()` |
| --- | --- | --- |
| Chrome / Edge（PC） | ○（Chrome 70+／Edge 79+） | 無し |
| Chrome（Android） | ○（105+） | 無し |
| Firefox | ○（153+。それ以前は自前の小窓ボタン） | 無し |
| Safari（Mac） | ○（13.1+） | ○（以前から。`-webkit-presentation-mode`） |
| Safari（iPhone／iPad） | ○（14+） | ○ |
| **Safari のホーム画面アプリ**（iPhone／iPad） | **×**（`NotSupportedError`。`pictureInPictureEnabled` は true のまま） | ○ だが `webkitSupportsPresentationMode("picture-in-picture")` が false |

- **「標準 API があるから入れる」だけでは足りない**。ホーム画面アプリでは「あるのに失敗する」ので、
  要素に聞く `webkitSupportsPresentationMode("picture-in-picture")` が**いまのところ唯一正しい判定**です。
- ただし Safari は**最初のフレームが出るまで対応を名乗らない**ことがあるので、読み込み前の `false` は
  「まだ分からない」として扱い、押したときに確かめます。
- Safari の小窓は**ブラウザーが持つ**（位置・大きさ・閉じるボタンはページから変えられない）。trk263 の
  「閉じても残す」は、Safari でも `video` が再生され続けるかぎり同じように働く見込みです（実機で要確認）。

## 2. やること（案）

### A. 2 つの API を1か所にまとめる（`pipBackend()`）

```
pipBackend({ standard, standardEnabled, webkit, webkitProbe, prefer })
  → "standard" | "webkit" | ""
```

- 純粋な計算として切り出し、`tests/trk264-pip-safari.test.mjs` で読みます（trk263 の「純粋な計算」と同じやり方）。

### B. 入る・出るを両対応

| | 標準 | webkit |
| --- | --- | --- |
| 入る | `await video.requestPictureInPicture()` | `video.webkitSetPresentationMode("picture-in-picture")`（同期・Promise ではない） |
| 出る | `await document.exitPictureInPicture()` | `video.webkitSetPresentationMode("inline")` |
| 出ているか | `document.pictureInPictureElement` | `video.webkitPresentationMode === "picture-in-picture"` |

- 標準で入ろうとして**断られたら**、webkit があれば**その場で入れ直す**（`prefer` を覚えて次回から短絡）。
- 入れたかどうかは**少し待って確かめる**（Safari は「何も起きずに終わる」ことがある）。

### C. 状態とイベント

- `pipIsOn()` を「どちらかの API で出ている」に。`pipNotice`／`keepPip`／`renderMedia` はそのまま使える。
- `webkitpresentationmodechanged` も拾う（Safari の ✕ は `leavepictureinpicture` を出さない）。

### D. 失敗を言葉にする

- 入れなかったときの案内（下の U3）。**「非対応」と「入れなかった」は別の言葉**にするのが親切です。
- ホーム画面アプリでは、押す前から理由を出せる（下の U2）。

### E. 設定の文言（4 言語）

- `mediaPipHint` の「（PC の Chrome／Edge／Safari。スマホは非対応）」を、いまの事実に合わせて書き直す。
- `mediaPipUnsupported` の言い方も、ホーム画面アプリの件に触れるかどうか決める。

### F. 見張り

- `tests/trk264-pip-safari.test.mjs`：`pipBackend` の判断（8〜10 件）＋配線（両方の API・イベント・文言 4 言語）。
- `tests/trk263-pip.test.mjs` は**そのまま通る**はず（`pipExitPlan` などの判断は変えない）。

## 3. 決めたこと（2026-11-02）

| # | 訊いたこと | 決まった答え | どうなるか |
| --- | --- | --- | --- |
| **U1** | Safari で、どの API を先に試すか | **`standard_first`** | 標準 `requestPictureInPicture()` を先に。**断られたら、その場で webkit へ**（`pipPrefer` に覚えて次回から短絡） |
| **U2** | ホーム画面アプリで使えないとき | **`disable_reason`** | 📌 は押せないまま、**title に理由**を出す（`mediaPipHomeApp`）。押しても何も起きない行き止まりを作らない |
| **U3** | 入れなかったときの案内 | **`new_key`** | 「画中画を開けませんでした（動画を再生してから、もう一度お試しください）」（`mediaPipFailed`）を 4 言語で追加。**「非対応」と「開けなかった」を分ける** |

## 4. 実機で見てほしいこと（Safari）

1. Mac の Safari：📌 で小窓が出る／✕ で戻る
2. Mac の Safari：📌 → プレーヤーを閉じる → **小窓が残って動き続ける**
3. iPad／iPhone の Safari：同じ2つ
4. **ホーム画面のアプリ**：📌 が押せない（理由が出る）／押して案内が出る（U2 の答え次第）
5. Safari で小窓を出したまま「ここにも表示」「画中画を終了」が効く

> 手元に Safari が無い場合は「未確認」と明記して出します（trk263 と同じ扱い）。
