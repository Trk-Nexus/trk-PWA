元：`docs/SKIN-RETURN-TRK267-2026-11-03.md`（Skin 側へ返した文書）§4 の表。
Skin 側は CLI 用のスキンを **①値（JSON）で渡す**か **②`.stpack`（パック）で渡す**かのどちらかを選べます。
どちらで来ても、**本体のコードを足さずに着られる**ように、受け口を先に用意しました。

## 3. 受け入れの 2 経路（どちらでも同じ見た目になる）

### ① 値で渡す（こちらが `js/data.js` に 1 枚入れる）

```json
{
  "id": "wizard-cli",
  "cat": ["dark", "wizard"],
  "colors": { "bg": "#020a04", "panel": "#031406", "text": "#c8ffc0", "accent": "#39ff14", "gold": "#ffb000" },
  "cli": { "font": "Cascadia Mono, monospace", "prompt": "λ", "caret": "#39ff14", "scan": 0.12 }
}
```

`colors` は `buildCustomSkin` が要る 5 つ（`bg`・`panel`・`text`・`accent`・`gold`）。`cli` は任意。

### ② パックで渡す（`.stpack` の `pack.json`）

```json
{ "skin": { "name": "Wizard CLI", "cat": ["wizard"], "colors": { … }, "cli": { … } } }
```

`sanitizeSkinDef` が `cat` と `cli` を残すようにしたので、**入れたパックのスキンが `auto` で選ばれます**
（棚の見え方は今までどおり `custom` 扱い＝`skinCatList` は変えていません）。

### 受け取る前に、倉庫側で確かめられる

```bash
node tools/check-cli-skin.mjs wizard-cli.json        # 人が読む
node tools/check-cli-skin.mjs wizard-cli.json --json # 機械向け
```

見るもの：`cat` の名乗り／`colors` の不足／コントラスト（文字 4.5:1・エラー 3:1）／`cli` の値が通るか。
計算は **アプリと同じ `js/data.js`** を読んで使うので、ここで通れば本体でも同じになります。
