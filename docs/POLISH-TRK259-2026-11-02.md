## 1. 推奨 1：目録の版を「端末の日付」に（R3 の仕上げ）

**レビューの指摘**：`String(updatedAt).slice(0, 10)` は **UTC の日付**。日本では朝 9 時前の更新が前日になる（例：11/03 08:00 JST → 「2026-11-02」）。

**どうしたか**：`catalogDay()` を通す。

```js
function catalogDay(raw) {
  const s = str(raw, 40);
  if (!s) return "";
  if (/^\d{4}-\d{2}-\d{2}$/.test(s)) return s;        // 日付だけの目録は動かさない
  const d = new Date(s);
  if (!Number.isFinite(d.getTime())) return s.slice(0, 10);
  const p = n => String(n).padStart(2, "0");
  return `${d.getFullYear()}-${p(d.getMonth() + 1)}-${p(d.getDate())}`;
}
```

- 端末の日付にした理由：**セット名（`2026-11-02-r10`）は日本の日付**で付けられているので、画面も同じ物差しにすると見比べられる
- 日付だけの目録（`2026-11-02`）は、時刻が無いので動かさない（タイムゾーンで 1 日ずれる事故を避ける）
- 読めない値は、これまでどおり先頭 10 文字（何も出さないより、元の文字を見せる）
- 公開：`Trk.packCatalog.catalogDay`（テストが直接呼べる）
